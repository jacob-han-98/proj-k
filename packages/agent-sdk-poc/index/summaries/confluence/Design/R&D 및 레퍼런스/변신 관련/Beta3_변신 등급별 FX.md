## 한 줄 설명
Project K의 변신 시스템에서 등급별(영웅, 전설, 신화) FX 컨셉을 정립하고, 변신 창과 인게임 환경에 맞는 리소스 제작 규격을 정의하는 문서.

## 숫자/상수/공식
- 변신 창 / 인게임 기준 6개 리소스
- 변신창 UI 및 인게임 최대 줌 추가 연출 2개 리소스 (영웅 제외)
- 영웅 ↔ 전설 디테일 차이 > 전설 ↔ 신화 디테일 차이
- 사슴 뿔 갈라짐: 영웅(1~2갈래) → 전설(조금 더 갈라짐) → 신화(뿔이 원형 문양을 뚫고 나옴)
