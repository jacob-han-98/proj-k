## 한 줄 설명
Project K의 MMORPG 사운드 구현을 위한 분류, 우선순위, 오디오 존 관리, 현황 및 항목별 상세 기획을 정의한 문서.

## 핵심 용어
- MMORPG 사운드 분류
- 리니지라이크
- 내 PC 관련
- PvP/RvR 관련
- 강적 (PvE)
- 위험 알림/경고
- BGM + 환경
- 오디오 존/볼륨
- 사운드 우선순위
- SFX (사운드 이펙트)
- Ambience (환경음)
- UI 사운드
- Voice (보이스)
- Cinematic (시네마틱)
- Modulator (피치/볼륨 변형)
- Foley
- Footstep (발자국)
- 히트 이펙트
- 크리티컬
- 필드보스/월드보스
- 나이아가라 시스템
- 애니메이션 몽타주/시퀀스

## 숫자/상수/공식
- 사운드 우선순위 1~9: 강적PvE(1) > 내 PC 관련(2) > 위험 알림/경고(3) > PvP/RvR 관련(4) > 다른 PC 관련(5) > UI(6) > 일반 몬스터(7) > 보이스(8) > BGM/환경(9)
- 이동 사운드 피치: 0.9~1.1, 볼륨: 0.8~1.0
- 평타 피치: 0.9~1.0, 볼륨: 0.8~1.0
- 강력한 스킬 피치: 0.95~1.05, 볼륨: 0.95~1.0
- UI 창 호출 시 배경 사운드 볼륨 감소: 50%
