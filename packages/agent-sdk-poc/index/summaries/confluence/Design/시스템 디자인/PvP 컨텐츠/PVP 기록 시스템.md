# PVP 기록 시스템 (요약)

> 출처: Confluence / PVP 기록 시스템
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/PvP 컨텐츠/PVP 기록 시스템/content.md

## 한 줄 설명
PK 발생 시 처치/사망/도움 기록을 남기고 위치 추적, 복수, 경계 등록 등의 부가 기능을 제공하는 시스템.

## 핵심 용어
- PVP 기록
- 처치(Kill)
- 사망(Death)
- 도움(Assist)
- 경계 대상
- 위치 추적
- 복수(Revenge)
- 도발 메시지
- 서버
- 매칭 서버(그룹)
- 사망 정보 팝업
- 대응 기능
- 경계 등록/삭제
- 필터링
- 처치 메시지
- 온라인/오프라인 상태
- 클래스
- 길드
- 피해량
- 대응 시간

## 숫자/상수/공식
- 기록 최대 개수: 100개
- 기록 보관일: 30일
- 경계 등록 최대 명수: 50명
- 대미지 기록 제한 시간: 10분
- 대응 시간: 24시간
- 위치 추적 지속 시간: 1분
- 위치 추적 최대 사용 횟수: 3회
- 복수 최대 사용 횟수: 3회
- 도발 메시지 최대 사용 횟수: 3회
- 복수 텔레포트 거리: 3m
- 위치 추적 비용: 10 다이아
- 복수 비용: 10 다이아
- 도발 메시지 비용: 10000 골드
