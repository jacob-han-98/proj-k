## 숫자/상수/공식
- 공성전 진행 시간: 셀레탄 30분, 소르브 40분
- 수성 승리 조건: 성물 미탈취 30분 유지
- 공성 승리 조건: 성물 각인 후 3분 유지
- 세율: 셀레탄 3%, 소르브 7%
- 수용 인원: 셀레탄(수성 150, 공성 250), 소르브(수성 150, 공성 500)
- 최대 공성 선포 길드: 30개
- 용병 최대 참가 인원: 50명
- 성물 각인 시 이동 속도 70% 감소
- 성물 각인 타이머: 약 3분
- 공성 시작 후 아무도 성물 각인 미시: 30분 경과 시 수성 승리
- 입장 비용: 10,000 골드(예시)
- 입장 가능 시간: 공성전 시작 30분 미만부터 종료까지
- 차감 비율: 100%, 50%, 0% (컨텐츠 세팅에서 설정 가능)
- 월드 공성전 승리 보상: 50,000 다이아(예시), 거래소 세율 15%(3개 서버 각 5%)
- 캐릭터 레벨 조건: 45 이상(공성전 메뉴 개방)
