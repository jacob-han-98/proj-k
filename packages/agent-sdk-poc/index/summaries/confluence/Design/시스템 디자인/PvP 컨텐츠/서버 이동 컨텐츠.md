## 한 줄 설명
플레이어가 타 서버로 이동하여 보스 약탈, PvE 활동, 공성전 난입 등을 통해 길드 간 분쟁과 협력을 야기하는 외교적 변수 시스템.

## 숫자/상수/공식
- 서버 이동권 1장 = 기본 1시간 이용 시간
- 최대 연장 시간: 3~5시간 (미정)
- 일일 최대 서버 탐험 시간: 3~5시간
- 복귀 캐스팅 타임: 약 10초
- 게임 종료 후 재접속 보장 시간: 10분 이내
- 보너스 보스 타임 어택: 제한 시간 내 처치 필요 (시간 초과 시 디스폰)
- 서버 그룹 내 필드 보스 스폰: 1개 서버에서만 보너스 보스 스폰
