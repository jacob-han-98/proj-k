## 한 줄 설명
여러 서버의 캐릭터들이 한시적으로 한 서버에 모여 보너스 보스를 공략하는 서버 이동 컨텐츠로, 필드 보스를 가장 먼저 처치한 서버에 추가로 스폰되는 보스를 다른 서버 유저들이 침공하여 처치하는 방식의 PvP 컨텐츠.

## 숫자/상수/공식
- 결계 반지름: 15m (원형 고정)
- AttackServerPortalAreaRadius: 30 (포탈 스폰 범위 반지름, cm 단위)
- AttackServerAreaOutTime: 10000 (타 서버 캐릭터 결계 밖 강제 귀환 대기 시간, 1000=1초)
- ReturnDurationTime: 3000 (귀환 프로그레스 시간, 1000=1초)
- 동일 서버 그룹 내 최대 1개 서버만 보너스 보스 스폰 가능
- 일일 횟수 제한 없음 (매회 필드 보스 스폰 시 확률 스폰)
