## 한 줄 설명
타 서버로 이동하여 일정 시간 동안 PvPvE를 진행하는 컨텐츠로, 입장권 기반의 상시 이용 가능한 서버 이동 컨텐츠이다.

## 핵심 용어
- 서버 탐험
- 서버 침공
- 로컬 서버 캐릭터 (원주민)
- 타 서버 캐릭터 (이방인)
- 코인 (Kore)
- 차원석
- 차원 이동 관리인
- 밀수 상인
- 경비병
- 입장권 (ExploreServerTicket)
- PvPvE
- 은신 상태
- 파티 규칙
- 포화 상태
- 월드맵
- 필드 선택
- 귀환 대기
- 네임 플레이트
- 시스템 메시지
- 버프 (ExploreServerStrangerBuff)

## 숫자/상수/공식
- ExploreServerDailyTime: 180분 (일일 이용 가능 시간)
- 코인 획득: 몬스터당 고정 1개
- NativeKoreBaseRatio: 원주민 기본 획득률(%) = 입력값 10,000 = 100%
- NativeKoreAdjustRatio: 원주민 레벨 차이 가산률(%)
- StrangerKoreBaseRatio: 이방인 기본 획득률(%) = 입력값 10,000 = 100%
- StrangerKoreEarningRatio: 이방인 레벨 차이 가산률(%)
- StrangerExpRatio: 이방인 경험치 획득률(%) = Default 10,000
- StrangerRewardRatio: 이방인 아이템 획득률(%) = Default 10,000
- StrangerGoldRatio: 이방인 골드 획득률(%) = Default 10,000
- ReturnDurationTime: 3000 (귀환 프로그레스 시간, 입력값 1000 = 1초)
- 로그아웃 시 남은 시간: 10초
- 귀환 10초 전 시스템 메시지 발동
