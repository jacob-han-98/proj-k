> 원본: packages/confluence-downloader/output/Design/시스템 디자인/UX UI 규칙/UX 규칙 문서/content.md

## 한 줄 설명
Project K의 UX 설계 규칙과 UI 컴포넌트 표준을 정의한 상위 페이지로, HUD 레이아웃, 해상도 대응, 제스처, 팝업, 알림 등 게임 내 사용자 경험 전반의 규칙을 모아둔 문서.

## 핵심 용어
- HUD 레이스
- HUD 기능적 레이아웃
- 해상도 대응
- 세이프 존 가이드라인
- 계층 구조(Hierarchy)
- 전환 UI FLOW
- 팝업 및 모달
- UI 딤드 관리
- 제스처
- 등급 표현
- 버튼 UI
- 아이템 위젯 구조
- 다이얼로그 팝업창
- 수량 슬라이더
- 리스트
- 폰트
- 알림 저장 규칙
- 시스템 메시지
- BM 상점 이동 FLOW
- UI LayerType 규칙

## 숫자/상수/공식
- 시간(Transition Duration): 0.3~0.8초 이내

## 참조 시스템
- 레드닷 시스템
- 해상도 대응 계획

## 주요 섹션
- 하위 문서 목차
- 규칙 (HUD 레이스, HUD 기능적 레이아웃, 해상도 대응 및 비율, 세이프 존 가이드라인, 계층 구조, 전환 UI FLOW 규칙 설정, 팝업 및 모달 정의, UI 딤드 관리 규칙 구현, 제스처, 등급 표현, 알림 저장 규칙, 시스템 메시지, BM 상점 이동 FLOW)
- UI 컴포넌트 (버튼, 아이템 위젯 구조, 다이얼로그 팝업창, 수량 슬라이더, 리스트, 폰트)
