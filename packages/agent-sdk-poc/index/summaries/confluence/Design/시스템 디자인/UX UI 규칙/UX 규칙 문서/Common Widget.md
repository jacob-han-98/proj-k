## 숫자/상수/공식
- 최근 검색 내역 최대 7개 항목
- 보상 아이콘 1줄 최대 7개
- 보상 아이콘 3줄 이상 시 하단 스크롤
- 확률 소수점 첫째 자리 반올림 표기
- 확률 항목 소수점 4번째 자리까지 표시
- 다이얼로 팝업 MAX 값 1100x680
- 텍스트 영역 너비 약 1000px
- Number Pad 기능: -1, +1, +10, +100, AC, MIN, MAX
- Number Pad_mini 기능: -1, +1, MAX
