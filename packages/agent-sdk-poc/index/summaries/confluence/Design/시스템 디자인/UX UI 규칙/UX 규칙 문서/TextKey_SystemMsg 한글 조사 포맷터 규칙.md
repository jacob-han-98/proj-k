> 원본: packages/confluence-downloader/output/Design/시스템 디자인/UX UI 규칙/UX 규칙 문서/TextKey_SystemMsg 한글 조사 포맷터 규칙/content.md

## 한 줄 설명
변수 텍스트(닉네임, 아이템명, 몬스터명 등) 뒤에 한글 종성 판별 시스템(hpp)을 사용하여 자연스러운 조사를 자동 붙이는 포맷터 규칙을 정의한다.

## 숫자/상수/공식
- 형식: `{변수순서}|hpp(받침있을때,받침없을때)`
- 예: `{0}|hpp(이,가)` → 받침 있음: 이, 받침 없음: 가
- 예: `레벨 10|hpp(을,를)` → 십으로 인식 → 레벨 10을
- 예: `{0}님, {1}|hpp(을,를) 획득하시겠습니까?` (다중 변수)
