## 한 줄 설명
Project K의 모든 UI 윈도우와 위젯을 계층화된 LayerType으로 체계화하여 일관된 UX 제공과 효율적인 관리를 정의하는 문서.

## 숫자/상수/공식
- LayerType 순서: 1~13 (높을수록 위에 출력)
- Notify_Info 애니메이션 속도: IN(0.4s) OUT(0.2s)
- Tooltip 한 화면 출력 개수: 1개
- PopUp 버튼 최대 개수: 3개
- 총 117개 WBP LayerType 변경 항목
