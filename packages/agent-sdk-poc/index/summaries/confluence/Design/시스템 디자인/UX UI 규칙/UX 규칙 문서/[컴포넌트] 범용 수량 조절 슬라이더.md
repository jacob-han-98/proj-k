## 한 줄 설명
아이템 제작, 거래소, 가방 파기, 창고 입/출고 등에서 사용되는 범용 수량 조절 컴포넌트의 UI/UX 규칙을 정의한 문서. 모바일(터치)과 PC(마우스/키보드) 플랫폼별 기능과 조작 방식을 명시한다.

## 숫자/상수/공식
- 최소 터치 버튼 크기: 44x44px 이상
- 단일 클릭 증감: +1, -1 단위
- 최소값: 1
- 퀵 버튼 단위 예시: +10, +100, +1000
