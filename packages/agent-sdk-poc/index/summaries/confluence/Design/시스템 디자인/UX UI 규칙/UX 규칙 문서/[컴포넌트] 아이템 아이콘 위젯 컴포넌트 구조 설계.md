## 한 줄 설명
게임 내 인벤토리, 창고, 상점, 제작 등 모든 UI에서 공통으로 사용되는 아이템 슬롯 위젯의 구조, 데이터 바인딩 규칙, 정보 표기 방식을 정의한 컴포넌트 설계 문서.

## 핵심 용어
- 아이템 슬롯 위젯
- Base Item
- Interaction Item
- Info Item
- 등급 프레임 (Grade)
- 아이템 이미지
- 자동 실행 표시
- 롱프레스 게이지
- 보유 수량 (Stack)
- 아이템 티어
- 강화/세공 수치
- 장착 아이콘
- 거래소/귀속 여부
- 레드닷
- 딤드 처리
- 체크 + 딤드
- 선택/포커스
- 속성 아이콘
- 세공 (소켓)
- 아이템 비교

## 숫자/상수/공식
- 보유수량 99 이상: +99로 표현
- 최대 소지량 이상: 999+
- 숫자 '0': 출력 제외
- 강화 단계: "+ 숫자" 표시 (예: +9)
- Depth 0 (최하단) ~ Depth 3 (최상단)
