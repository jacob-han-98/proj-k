## 한 줄 설명
내비게이션형 팝업 시스템을 통해 UI 계층 구조를 정의하고, 사용자가 깊은 뎁스(상세 정보 → 강화 → 재료 획득처 → 거래소)에서도 뒤로가기로 원래 맥락으로 복귀할 수 있도록 스택 기반 히스토리 관리 방식을 설계한다.

## 숫자/상수/공식
- Window 최대 스택 개수: 5~10개
- Stack 최대 개수: 10개 (초과 시 가장 오래된 Stack [1] 삭제)
- 장시간 미조작 임계값: 10분 이상 UI 스택 유지 시 강제 초기화
