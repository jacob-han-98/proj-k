# 등급 표시 규칙 (요약)

> 출처: Confluence / Design/시스템 디자인/UX UI 규칙/UX 규칙 문서/등급 표시 규칙
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/UX UI 규칙/UX 규칙 문서/등급 표시 규칙/content.md

## 한 줄 설명
게임 내 아이템 및 콘텐츠의 등급을 6단계로 분류하고, 각 등급별 시각적 표현과 UX 연출 규칙을 정의하는 문서.

## 핵심 용어
- 등급 (Grade)
- 일반 (Common)
- 고급 (Uncommon)
- 희귀 (Rare)
- 영웅 (Unique)
- 전설 (Legendary)
- 신화 (Myth)
- 아이콘 BG 컬러
- 희소성 시각화
- 인벤토리
- 장비 아이템
- 변신/크리처
- 스킬 (액티브/패시브)
- 아이템 툴팁
- 카드 뒤집기 연출
- 상자 개봉 연출

## 숫자/상수/공식
- 총 6가지 등급 존재
- 영웅 등급: 1단계 배경 연출
- 전설 등급: 2단계 배경 연출
- 신화 등급: 최고 등급 단계 배경 연출

## 참조 시스템
- 장비 아이템 발주 계획

## 주요 섹션
- 문서 개요
- 목표
- 등급 가이드
- 등급 별 정의 및 시각적 가이드
- 상황 별 사용 등급 가이드
- 등급 체계에 따른 UX 디자인 고려 사항
- 고등급의 희소성 시각화
