# 제스처 기능 (요약)

> 출처: Confluence / Design/시스템 디자인/UX UI 규칙/UX 규칙 문서/제스처 기능
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/UX UI 규칙/UX 규칙 문서/제스처 기능/content.md

## 한 줄 설명
Project K 모바일 게임의 제스처 입력 시스템을 정의하며, 특히 스와이프 기능의 수평 방향 구현 조건과 터치 영역, 드래그 거리 기준을 상세히 규정한다.

## 핵심 용어
- 제스처 기능
- 탭 (Tap)
- 더블 탭 (Double Tap)
- 롱 프레스 (Long Press)
- 드래그 (Drag)
- 스와이프 / 플릭 (Swipe/Flick)
- 패닝 (Panning)
- 핀치 (Pinch & Spread)
- 회전 (Rotate)
- 스크롤 (Scroll)
- 드래그 앤 드롭 (Drag & Drop)
- 터치 시작 지점
- 유효 스와이프 영역
- 드래그 속도 감도
- 전환 불가 조건
- 이동 거리

## 숫자/상수/공식
- 터치 시작 영역: 화면 좌/우측 가장자리로부터 20~30% (약 25%) 이내
- 최소 전환 거리: 화면 폭의 70~80% (약 25%) 이상
- 드래그 이동 후 터치 해제 시점: 70~80% 이동 이후
