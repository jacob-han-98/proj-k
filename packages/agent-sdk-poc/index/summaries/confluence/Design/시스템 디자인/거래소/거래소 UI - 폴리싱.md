## 숫자/상수/공식
- MarketInfoDays = 28 (거래소 시세 기준 일자)
- MarketInfoMaxCount = 50 (거래소 최근 거래 목록 최대 개수)
- MarketInfoSellMaxCount = 999 (거래소 1개 항목 판매 최대 개수)
- 일괄 구매 최대 개수 = 10개
- 장비 아이템 최대 판매 수량 = 1개 (고정)
- 소비 아이템 최대 판매 수량 = 999개 (ContentSetting 참조)
- 최대 입력 값 = 999,999,999
- 거래소 시세 업데이트 텀 = 최대 10초
- 개당 판매 금액 소수점 = 둘째 자리까지
