## 한 줄 설명
Project K의 던전 콘텐츠별 드랍 아이템 구성과 드랍률을 정의하는 경제 밸런스 문서. 일일 던전 A/B, 주간 던전, 인터서버 던전, 정령의 탑에서 획득 가능한 재화, 재료, 장비의 종류와 확률을 명시한다.

## 숫자/상수/공식
- 일일 던전 난이도: 필드 대비 70%
- 주간/인터서버 던전 난이도: 필드 대비 150%
- 일일 던전 A 경험치: 필드 대비 150%
- 성장의 증표 획득: 최저레벨 기준 1시간에 약 100개
- 승천의 인장_투사 드랍률 비율: 일일 2:2:6 (주간 기준)
- 주간 던전 승천의 인장_투사: 1시간에 약 1개
- 골드 아이템 획득량: 동레벨 필드 대비 5배 (1시간 기준)
- 장비 강화 재료 드랍률: 3.5% ~ 7% (3초 사냥 기준 41~84개)
- 장비 강화 재료 배포비율: 방어구 6 : 무기 3 : 장신구 1
- 최저층 1시간 기준 안전강화: 무기 2개, 방어구 6개, 장신구 3개
- 일일 던전 A 승천의 인장_투사 드랍률: 0.25% → 0.5% → 0.75%
- 일일 던전 B 스킬 강화 재료 드랍률: 0.3% ~ 1%
- 일일 던전 B 제작 기본 재료 드랍률: 2.5% (약 30개) → 5% (60개)
- 일일 던전 B 제작 코어 재료 드랍률: 0.01%
- 제작 기본 재료 업그레이드: 하위 재료 10개 → 상위 재료 1개
- 제작 코어 재료 획득 감성: 1주일에 1개 (20개 모으면 약 5개월)
- 던전 드랍 아이템 거래가능 비율: 쌀먹의 70~80%
