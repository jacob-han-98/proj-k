# 승천의 인장 밸런스 (요약)

## 한 줄 설명
승천의 인장(Seal) 강화 시스템의 획득처, 소비처, 주간 수급량, IBT 밸런스를 정의하는 경제 밸런스 문서.

## 핵심 용어
- 승천의 인장
- 인장의 파편 (ItemId 110)
- 찬란한 인장의 정수 (ItemId 111)
- 인장 강화 (Seal Leveling)
- 인장 Reroll (재연성)
- MonsterReward
- QuestRandomReward
- ItemReward
- 일일던전1, 일일던전2, 주간던전
- Seal 1000 (Warrior), Seal 2000 (Guardian), Seal 3000 (Magician)
- SealLevelData
- MaterialClassID
- IBT (Internal Beta Test)
- 드랍률
- 성공률
- 실패감안 누적소모

## 숫자/상수/공식
- Prob 기준: 1,000,000 = 100%
- 일일던전 시간제한: 하루 1시간
- 주간던전 시간제한: 주 8시간
- 5초당 1킬 기준 (시간당 720킬)
- 일일 퀘스트 완료 상한: 10회 (MaxComplete = 10)
- 퀘스트 보상 풀 크기: 5종
- 인장 파편 당첨 확률: 20% (1/5)
- 당첨 시 수량: 5개
- 1종 풀강 소모: 9,733개 (성공 시 기준)
- 3종 풀강 소모: ~29,199개 (성공 시 기준)
- 인장 최대 레벨: 50
- 인장 종류: 3종 (1000, 2000, 3000)
- Reroll 총 소모량: 45개 (3개 인장 × 5회 리롤 구간)
- IBT 드랍 수량: 1~3개 (균등 확률, 평균 2개)
- IBT 일일던전 1층 확률: 10%
- IBT 일일던전 2층 확률: 15%
- IBT 일일던전 3층 확률: 20%
- IBT 주간던전 확률: 30%
- IBT 주간 합계 수급: 7,558개
