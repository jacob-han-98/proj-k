## 숫자/상수/공식
- 서버당 AU 1.5만명 기준 (동접 5000명)
- 컨텐츠 공유 서버군 5개
- 1인 1시간 장비 획득 3.6~6개 = 0.5% 드랍률
- 사냥 기준 3초~5초 주기
- 가방 여분 칸 수에 따라 8시간~14시간 사이 장비 추가 획득 불가
- 획득 장비 중 20% 거래소 등록 가능
- 월 장비 판매 수익 약 9만원
- 영웅 등급 무기: 월 평균 5개
- 영웅 등급 방어구(파츠): 월 평균 5개
- 영웅 등급 장신구: 월 1개
- 일반 T1: 1일 이내 / 고급 T1~T3: 1일 이내 / 희귀 T1: 3일 / 희귀 T2: 1주 / 희귀 T3: 2주 / 희귀 T4: 1개월 / 영웅 T1: 3개월 / 영웅 T2: 6개월 / 영웅 T3: 9개월 / 영웅 T4: 12개월
- IBT 기간: 약 1주일
- IBT 일일 플레이 시간: 1~3시간
- IBT 체험 감성: 통상 1/5 정도
- IBT 인원: 최대 200명 추정
