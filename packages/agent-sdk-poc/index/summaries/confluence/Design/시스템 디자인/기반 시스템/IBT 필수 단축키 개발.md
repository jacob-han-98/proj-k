## 숫자/상수/공식
- 로드나인 퀵슬롯: 1~8
- 로드나인 확장 퀵슬롯: Shift+1~8
- 로드나인 콘텐츠 특수 퀵슬롯: F5~F8
- 뱀피르 확장 퀵슬롯: 1~5
- 뱀피르 퀵슬롯: F1~F5
- 뱀피르 전투 프리셋: 7, 8, 9, 0
- 나이트 크로우 단축키: 1~8
- 나이트 크로우 파티원 선택: F1~F4
- Project K 아이템 퀵슬롯 첫 번째 줄: F1~F4
- Project K 아이템 퀵슬롯 두 번째 줄: Ctrl+F1~F4
- Project K 아이템 퀵슬롯 세 번째 줄: Shift+F1~F4
- Project K 스킬 퀵슬롯 첫 번째 줄: 1~4
- Project K 스킬 퀵슬롯 두 번째 줄: Ctrl+1~4
- Project K 스킬 퀵슬롯 세 번째 줄: Shift+1~4
- Project K 파티원 선택: Alt+1~4
