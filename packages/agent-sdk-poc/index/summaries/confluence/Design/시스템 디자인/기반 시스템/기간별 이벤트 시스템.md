## 한 줄 설명
기간별로 미션이 순차적으로 개방되며, 개별 미션 완료 시 누적 점수를 획득하여 보상을 수령하는 이벤트 시스템의 규칙 및 UI 명세.

## 숫자/상수/공식
- 최대 8개의 기간 탭
- 남은 시간 1일 이상 = [00일 00시간] 표기
- 남은 시간 1일 미만 = [HH:MM:SS] 표기
- 뱀피르 - 영웅의 서약: 총 8주, 주차별 5개 미션
- 뱀피르 - 영웅의 서약: 4주차 누적 점수 20점 필요 (영웅 변신 획득)
- 뱀피르 - 영웅의 서약: 8주차 누적 점수 40점 필요 (영웅 탈것 획득)
- 개별 미션 완료 시 누적 점수 1점 획득 (뱀피르 예시)
