## 한 줄 설명
멀티 캐릭터 시스템의 UI/UX를 개선하여 캐릭터 육성 편의성을 높이고, 대시보드에서 캐릭터 상태를 한눈에 파악하며 빠른 캐릭터 전환과 오프라인 모드 관리를 가능하게 하는 기획.

## 숫자/상수/공식
- 오프라인 모드 최대 개수: ContentSetting.xlsx의 <OfflineModeMaxCount> 참조
- 캐릭터 항목 최대 출력 개수: 4개
- 물약 부족 기준: 50개 이하
- 인벤토리 슬롯 경고 기준: 90% 이상 또는 슬롯 맥스
- 가방 슬롯 색상 변경 규칙: 80% 미만(하얀색), 80% 도달(주황색), 100% 도달(붉은색)
- 경험치 표현: 소수점 4자리까지
