## 한 줄 설명
온라인 및 오프라인 자동 사냥 모드에서 스케줄러에 의해 퀘스트, 던전, 사냥터를 자동으로 진행하는 시스템으로, 자동 전투 및 자동 정비 기능과 연동된다.

## 숫자/상수/공식
- 개방 조건: Lv.30 (주간 던전 개방 레벨)
- 자동 정비 기본 이용 시간: 8시간
- BM 구매 시 추가 확장: 16시간
- 최대 이용 시간: 24시간
- 일일 던전 시간 설정: 최소 1시간, 최대 24시간
- 사망 횟수 설정: 최소 1회, 최대 10회
- 빠른 부활: 5초 후 버튼 활성화 (기본 30초 대기)
- 수동 이동 거리 기준: 50m 초과 시 텔레포트 처리
- 위치 기억 미활동 시간: 5분 동안 아무 행동 없을 경우 서포트 모드 중단
- 추천 퀘스트 선택 개수: 최대 10개
- 시간 던전 스킵 조건: 1분 미만 남음 또는 만료
