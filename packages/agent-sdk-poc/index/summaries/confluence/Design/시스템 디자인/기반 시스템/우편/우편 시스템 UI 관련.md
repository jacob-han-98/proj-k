## 한 줄 설명
Project K 모바일 MMORPG의 우편 시스템 UI/UX 설계 문서로, 우편함 호출, 우편 목록 표시, 상세 내용 팝업, 첨부물 지급 화면 등 전체 우편 시스템 인터페이스를 정의한다.

## 핵심 용어
- 우편함 탭 (캐릭터/서버/계정/상점/길드/개인)
- 레드닷
- 첨부물
- 받기 버튼
- 모두 받기
- 모두 읽기
- 일괄 삭제
- 우편 상세 내용 UI
- 첨부물 지급 UI
- 아이템 정보 UI
- 우편 제목
- 발신자
- 발신 일시
- 만료까지 남은 기한
- 읽음/읽지 않음 상태
- 받음/받지 않음 상태
- 우편함 정리 알림
- 청약철회
- 우편 작성 기능

## 숫자/상수/공식
- 최대 우편 개수: 100개
- 우편함 정리 알림 기준: 90% 이상 (90개)
- 첨부물 슬롯 제한: 5개
- 첨부물 아이콘 배치: 5열
- 첨부물 정상 표시: 10개 (2열)
- 청약철회 기간: 대체적으로 14일
