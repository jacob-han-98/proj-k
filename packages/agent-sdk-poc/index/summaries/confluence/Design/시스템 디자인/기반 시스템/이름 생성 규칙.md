유저가 직접 생성하는 캐릭터명, 길드명, 위치 기억 이름에 대한 검증 규칙과 금칙어, 허용어 관리 기준을 정의한 문서.

- 시각적 유사성 그룹핑

- 시스템 메시지

## 숫자/상수/공식
- 캐릭터명/길드명 한글: 2~8자
- 캐릭터명/길드명 영문: 2~12자
- 캐릭터명/길드명 숫자+영문: 2~12자
- 캐릭터명/길드명 숫자+한글: 2~8자
- 캐릭터명/길드명 숫자+한글+영문: 2~8자
- 위치 기억 이름: 2~12자
- 동일 문자 4회 이상 반복 금지
- I, i, l, 1 → @ 치환
- O, 0, D → $ 치환
- W, w, v → # 치환
