## 한 줄 설명
장시간 방치 시 기기 성능을 보호하고 전력 소모를 최소화하면서 성장/보상 정보를 모니터링할 수 있는 저전력 상태 시스템.

## 핵심 용어
- 절전 모드
- 수동 진입
- 자동 진입
- 드래그 투 언락
- 프로그레스 바
- 대시보드
- 리소스 최적화
- 프레임 제한
- 화면 번인
- 백그라운드 데이터 통신
- 알림
- PIP 모드
- 서포트 모드
- 자동 사냥
- 자동 이동
- 퀘스트
- 거래소
- 시스템 메시지
- 채팅
- 물약

## 숫자/상수/공식
- 자동 진입 시간: 1분/3분/5분/사용 안 함 (기본값 3분)
- 프레임 제한: 15fps~20fps 이하
- 경험치 표시 소수점: 넷째자리까지
- 인벤토리 색상 변경 기준: 90% 미만(흰색), 90% 이상(주황색), 100%(빨간색)
- 시간 당 경험치 표기: 1만 미만(400/h 형식), 1만 이상(1만/h 형식), 1억 이상(1억/h 형식)
- 예상 레벨업 시간: 24시간 이상은 일(d) 단위로 표시

## 참조 시스템
