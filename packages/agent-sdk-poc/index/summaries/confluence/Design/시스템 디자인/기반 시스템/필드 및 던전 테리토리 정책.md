## 한 줄 설명
필드 및 던전 제작 시 테리토리 세팅에 참고할 표준 정책을 정의하며, WorldTerritory.xlsx 테이블 입력 가이드와 볼륨 배치 규칙을 제시한다.

## 숫자/상수/공식
- CombatZoneType 우선순위: 혼돈(Chaos) > 마을(Town) > 안전(Safety) > 일반(Normal)
- Priority: 숫자가 클수록 우선순위가 높음
- RespawnVolumeId 복수 입력 시: 길찾기 거리 기준 가장 가까운 리스폰 볼륨에 리스폰 처리
