## 숫자/상수/공식
- 자동 전투 범위: 최소 5m, 최대 40m, 기본값 20m
- 전투 기록 저장 조건: 1분 이상 / 3분 이상 / 5분 이상 / 10분 이상
- 화면 재생 속도: 낮음(15fps) / 중간(30fps) / 높음(60fps) / 매우 높음(120fps) / 무제한
- HP 물약 자동 사용 비율: 0~100 (기본값 80)
- PVP 시 HP 물약 자동 사용 비율: 0~100 (기본값 100)
- 플레이어 표시 인원 제한: 30 / 50 / 100(기본값) / 200 / 무제한
- UI 배율: 매우 작게(50%) / 작게(75%) / 보통(100%) / 크게(125%) / 매우 크게(150%)
- 마우스 커서 크기: 보통(100%) / 크게(150%) / 매우 크게(200%)
- 볼륨 범위: 0~100 (기본값 100)
- 절전 모드 설정: 3분 / 5분 / 10분 / 사용 안함(기본값)
- 스킬 자동 사용 MP 제한: 70 / 끄기(기본값) / 켜기
- 공격 대상 우선 순위: 1순위~7순위 (각각 끄기/켜기 선택 가능)
- 그래픽 품질 단계: Low(낮음) / Medium(중간) / High(높음) / Epic(매우 높음) / Cinematic(노출/사용하지 않음)
