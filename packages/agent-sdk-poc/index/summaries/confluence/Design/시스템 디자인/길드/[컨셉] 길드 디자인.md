## 숫자/상수/공식
- 길드 이름: 최대 8자(영문 16자)
- 길드 소개: 최대 16~20자
- 생산 재료 최소: 10개 / 제작 완제 1개
- 버프 효과 곡선: 지수함수 형태
- 협동 보스 최소 인원: 고투력 3~4인 또는 저투력 12~15인 이상
- 길드 레이드 주간 횟수: 1회(오딘은 2회)
- 길드 기부 횟수: 나이트 크로우 기준 각 3회
- 길드 탈퇴 후 재가입 불가: 24시간
