# 길드 금고 시스템 (요약)

> 출처: Confluence / 길드 금고 시스템
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/길드/길드 금고 시스템/content.md

## 한 줄 설명
길드 단위로 획득한 재화(다이아)와 아이템을 보관하고 길드원들에게 분배하는 시스템으로, 기여도 기반 분배 및 분배 기록 관리 기능을 포함한다.

## 핵심 용어
- 길드 금고
- 길드 레이드
- 공성전
- 길드 다이아
- 주간 기여도
- 아이템 분배
- 다이아 분배
- 균등 분배
- 기여도 분배
- 분배 기록
- 일일 분배 제한
- 미참여 인원 제외
- 참여 기반 선택
- 개별 분배
- 일괄 분배
- 분배 확정
- 우편 발송
- ContentSetting
- MailTemplate
- MsgEnum

## 숫자/상수/공식
- 보관 최대 개수: 100개
- 금고 공간 부족 기준: 5칸 미만
- 일일 다이아 분배 제한: 100,000 다이아 (약 27만원 가치)
- 분배 기록 보관일: 30일
- 균등 분배 나머지 처리: 기여도 순서대로 1 다이아씩 추가
- 기여도 분배 공식: 개인별 주간 기여도 / 전체 기여도 합산 × 분배금액
