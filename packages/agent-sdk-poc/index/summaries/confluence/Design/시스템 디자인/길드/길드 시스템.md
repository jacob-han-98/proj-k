## 숫자/상수/공식
- 길드 메뉴 개방 조건: 레벨 15 이상
- 길드 이름: 2자~8자, 중복 불가
- 길드 소개: 최대 20자
- 추천 길드 최대 표시: 30개
- 길드 랭킹 표시: 100위까지
- 길드 랭킹 갱신 주기: 1분마다 (매주 월요일 오전 5시 초기화)
- 추천 길드 최소 출석율: 30% 이상 (0.3 <= 전날 출석 인원/현재 가입한 길드원)
- 신입 길드원 유지 기간: 24시간
- 길드 탈퇴/해산/추방 후 가입/창설 불가 기간: 24시간
- 길드 공지사항: 최대 4줄, 최대 100자
- 길드 연혁 최대 로그: 100개
- 길드 적대 등록 최대: 20개
- 길드 우호 등록 최대: 20개
- 길드 우호 요청/수락 대기 최대: 각 20개
- 길드 초대 최대: 20개
- 길드 가입 신청 최대: 30개
- 길드 가입 신청 승인 최대: 100개
- 길드명 변경 쿨타임: 7일
- 길드장 미접속 자동 위임 기준: 14일 이상
- 자동 추방 미접속일: 최소 1일, 최대 30일
- 자동 추방 주간 기여도: 최소 1점, 최대 10만점
- 길드 검색: 1자 검색 허용 (첫 글자만)
- 길드 해산 대기 시간: 24시간
