# 공허의 틈새(인터서버던전) 시스템 고도화 (요약)

> 출처: Confluence / PK
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/던전/공허의 틈새(인터서버던전) 시스템 고도화/content.md

## 한 줄 설명
인터서버 전용 던전 '공허의 틈새'의 리뉴얼 시스템으로, 초식/육식 유저 분리, 이원화 재화(토벌/투쟁의 훈장), 서버 단위 진영전 및 보스 쟁탈 중심의 게임플레이를 정의한다.

## 핵심 용어
- 공허의 틈새
- 카오스(인터서버전용던전)
- 토벌의 훈장(VoidRiftMedalPve)
- 투쟁의 훈장(VoidRiftMedalPvp)
- 하층(3개 서버 그룹)
- 상층(6개 서버 그룹)
- 인터서버 월드
- 보스 몬스터
- 진영전(RVR)
- 최종 타격(막타)
- 승리 보상
- 참여 보상
- 훈장 전용 상점
- 자율 선택 결제
- 서버 매칭 현황
- 어뷰징 방지
- 연속 처치 쿨타임
- 전투력(CP) 비율
- 사망 페널티 면제
- 주간 획득 한도

## 숫자/상수/공식
- 하층: 3개 서버 그룹
- 상층: 6개 서버 그룹
- 투쟁의 훈장 획득 수식: `VoidRiftPvpBaseRewardMedal * (방어자 전체 전투력 / 공격자 전체 전투력)`
- 최소 전투력 비율 하한선: `VoidRiftPvpRewardMinCpRatio` (예: 0.7)
- 동일 타겟 연속 처치 쿨타임: `VoidRiftPvpKillCooldownTime` (예: 300초)
- 주간 획득 한도 초기화: 매주 월요일 05:00
- 갱신 버튼 쿨타임: 3초
- 최대 보유 한도: `Currency` 테이블의 `MaxAmount` 값
- 주간 합산 획득 한도: `VoidRiftWeeklyLimitMedalCombined`
