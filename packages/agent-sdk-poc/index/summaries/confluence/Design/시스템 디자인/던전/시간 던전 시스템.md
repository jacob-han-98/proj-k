# 시간 던전 시스템 (요약)

## 한 줄 설명
필드 외에 한시적으로 이용 가능한 사냥형 컨텐츠로, 시간정량형(TimeDungeon)과 입장권소모형(TicketDungeon) 두 가지 방식의 던전 시스템을 정의한다.

## 핵심 용어
- TimeDungeon (시간정량형 던전)
- TicketDungeon (입장권소모형 던전)
- DungeonPlayTime (던전 플레이 시간)
- FreeTime (무료 시간)
- RechargedTime (충전 시간)
- ChannelType (채널 타입)
- Fixed (고정 채널)
- Dynamic (동적 채널)
- 퍼시스턴트형 (Persistent)
- MaxCapacity (최대 인원 수)
- ThresholdRate (채널 한계 인원)
- DungeonLimitTime (던전 제한 시간)
- EntranceCostCurrency (입장 재화)
- EntranceCostItem (입장 아이템)
- DungeonReward (던전 보상)
- CombatZoneTypeEnum (전투 존 타입)
- Hunting (사냥형)
- Chaotic (혼돈형)
- Safety (안전형)
- InstanceTrigger (인스턴스 트리거)
- PlayerRespawnType (플레이어 부활 타입)

## 숫자/상수/공식
- 충전 시간 최대값: 9999시간
- Dynamic 채널 MaxCapacity 예시: 50명
- Dynamic 채널 ThresholdRate 예시: 70%
- Fixed 채널 MaxCapacity 예시: 500명
- Fixed 채널 ChannelCount 예시: 2개
- 퍼시스턴트형 ChannelCount: 1개
- DungeonRewardList 최대 5개 (TimeDungeon)
- NormalRewardList 최대 10개 (TimeDungeonLevelInfo)
- BossRewardList 최대 10개 (TimeDungeonLevelInfo)
- DungeonNormalRewardList 최대 10개 (TicketDungeonLevelInfo)
- Level = 0: 층 정보 UI 숨김
