## 한 줄 설명
정령의 탑의 스테이지 구성(섬멸전, 방어전, 공격전, 보스전)과 각 스테이지별 몬스터/기믹 배치, 구현 필요 요소를 정의하는 기획 문서.

## 핵심 용어
- 정령의 탑
- 섬멸전
- 방향전
- 공격전
- 보스전
- 스폰 트리거
- 어그로
- 선공몹
- 오브젝트형 아군 NPC
- 버프 해제 트리거
- 무적 상태
- 장판 패턴
- AOE 데칼
- 타겟 점사
- 버프 트리거
- 시간차 공격
- 클리어 조건
- 제한 시간
- 인식 범위

## 숫자/상수/공식
- 3마리 1그룹 단위
- 3~5번 순차적 그룹 스폰
- 20초 경과 시 다음 그룹 스폰 (예시)
- n마리 처치 시 버프 해제 (변수)
- n초 후 데칼 위치 피해 (변수)

## 참조 시스템
- 정령의 탑 기본 시스템 기획 (Confluence 페이지)
- 기믹전 기획서

## 주요 섹션
- 개요
- 기획 의도
- 내용 요약
- 상세 기획
- 섬멸전: 제한 시간 내 전체 몬스터 처치
- 방어전: 아군 오브젝트 수호
- 공격전: 특정 타겟 점사 및 기믹 파훼
