## 한 줄 설명
도깨비와 함께 전투하는 클리어&랭킹 기반 1인 인스턴스 던전으로, 최대 100층의 시즌제 컨텐츠이며 층별로 다양한 전투 방식과 난이도를 제공한다.

## 숫자/상수/공식
- 최대 층수: 100층
- 각 층 전투 제한 시간: 90초
- 각 층 입장 후 스테이지 시작 대기 시간: 10초
- 주간 무료 입장 횟수: 30회 (1개월 기준)
- 4주 기준 도전/클리어 가능 횟수: 120회
- 전용 버프 보상 최대 선택 개수: 3개
- 랭킹 DB 저장 범위: 1위~100위
- 시즌 보상 지급 시점: 시즌 종료 시간 이후 10분 뒤
- 클리어 타임 저장: 100층에서만 저장
- 동일 층 여러 번 클리어 시: 가장 짧은 시간만 저장
