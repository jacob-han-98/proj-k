## 숫자/상수/공식
- 최대 탑 층수: 100층
- 최대 버프 목록 출력: 100개
- 최대 클리어 보상 아이콘: 30개
- 버프 이름 출력 글자 수: 12글자
- 난이도 쉬움 판정: 층 권장 전투력 < 플레이어 전투력의 90% (0.9)
- 난이도 어려움 판정: 층 권장 전투력 > 플레이어 전투력의 110% (1.1)
- 난이도 보통 판정: 플레이어 전투력의 90% ~ 110% 사이
- 비활성화 아이콘 알파값: 0.5 ~ 0.3
- 퍼센트 값 출력: 최대 만 단위, 소숫점 2번째 자리
- 정수 값 출력: 최대 십만 단위
- 중첩 값 최대 자릿수: 2자릿수
