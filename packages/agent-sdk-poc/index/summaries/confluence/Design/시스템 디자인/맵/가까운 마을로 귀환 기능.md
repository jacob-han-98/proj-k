# 가까운 마을로 귀환 기능 (요약)

> 출처: Confluence / Design/시스템 디자인/맵
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/맵/가까운 마을로 귀환 기능/content.md

## 한 줄 설명
현재 위치의 WorldTerritory ID를 기준으로 연결된 RespawnVolumeId로 텔레포트하는 기능. 복수 개의 RespawnVolumeID가 있을 경우 패스 거리 기준으로 가장 가까운 볼륨으로 이동.

## 핵심 용어
- 가까운 마을로 귀환 기능
- WorldTerritory
- RespawnVolumeId
- 텔레포트 볼륨
- 테리토리 우선순위
- 패스(길찾기) 거리
- 미발견지역
- 인스턴트 던전
- 퀘스트 레벨
- 인스턴트 레벨
- 귀환 주문서
- ItemConsumeClass
- ConsumeType
- TeleportTown
- Textkey
- Item_CanFindNearByTown

## 숫자/상수/공식
- RespawnVolumeId = 1 (예시: 오염된 농장)
