# 월드맵 개선 (요약)

> 출처: Confluence / Design/시스템 디자인/맵/월드맵 개선
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/맵/월드맵 개선/content.md

## 한 줄 설명
기존 월드맵 시스템을 바탕으로 대륙맵 화면의 국가 아이콘, 버튼, 중간맵 출력 기능을 정식 버전으로 구현하는 작업을 정의한다.

## 핵심 용어
- 월드맵
- 대륙맵
- 중간맵
- 국가 아이콘 (flag)
- WorldCountry 테이블
- WorldTerritory 테이블
- RegionType
- Town
- Product 컬럼
- SystemMSG
- TextKey
- WorldCountryId
- WorldRegionTypeEnum
- 미제작 지역
- 토스트 메시지
- Offset 이동
- 위젯

## 숫자/상수/공식
- 마을 id값이 낮은 마을을 대상으로 선정 (2개 이상일 경우)
- 중앙 영역을 기준으로 X 또는 Y축 값을 Offset 이동하여 최대 가용 범위로 출력

## 참조 시스템
- PK_월드맵 시스템.xlsx

## 주요 섹션
- 개요
- 개발 목적
- 작업 사항
- 기능 제작 사항
- 대륙맵 국가 아이콘 출력
- 국가 버튼 (국가+텍스트) 클릭 시 처리 사항
- 참조 자료
- 관련 테이블
- 알파2 기준 작업 진행 사항
