# 경비병 피아 식별 및 몬스터 말풍선 시스템 (요약)

> 출처: Confluence / 경비병 피아 식별 및 몬스터 말풍선 시스템
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/몬스터/경비병 피아 식별 및 몬스터 말풍선 시스템/content.md

## 한 줄 설명
타 서버 유저를 공격하고 동일 서버 유저는 공격하지 않는 경비병 NPC의 피아 식별 시스템과, 몬스터 및 NPC가 아군/적군에 따라 선택적으로 말풍선을 출력하는 시스템을 정의한다.

- BattleObjectType

- OtherServerPC
- MonsterTypeEnum
- BattleObjectTypeRelation
- SpeechBubbleId
- SpeechDisplayType
- BattleRelationTypeEnum
- ReactionRadius

- NPCClass

- Hostile
- Neutral
- PassivePC
- AggressivePC
- Monster

## 숫자/상수/공식
- MonsterTypeEnum CrossWorldGuard = 6
- BattleObjectTypeEnum CrossWorldGuard = 13
- BattleObjectTypeEnum OtherServerPC = 12
- BattleObjectTypeEnum PassivePC = 0
- BattleObjectTypeEnum AggressivePC = 1
- BattleObjectTypeEnum Monster = 2
- 경비병 ReactionRadius 예시 = 500
- 고블린 ReactionRadius 예시 = 300
- SpeechBubbleId 경비병 예시 = 1001, 1002
- SpeechBubbleId 고블린 예시 = 2001

- PK_피아 식별.xlsx
