# 보스 스케쥴 시스템 UI (요약)

> 출처: Confluence / 보스 스케쥴 시스템 UI
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/몬스터/보스 스케쥴 시스템/보스 스케쥴 시스템 UI/content.md

## 한 줄 설명
보스 몬스터의 출현 일정을 플레이어에게 알리고 관리하기 위한 UI 시스템으로, HUD 아이콘, 스케쥴 리스트, 월드맵 연동, 토스트 메시지 등을 포함한다.

## 핵심 용어
- HUD 아이콘
- 스케쥴 UI
- 월드맵
- 토스트 메시지
- 네임드 몬스터
- 보스 몬스터
- 알림 설정
- 필터 (정렬)
- 텔레포트
- 출현 중
- 미 출현
- 미 확인
- 리스트 정렬
- 등장 시간
- 등장 지역
- 몬스터 정보
- 보상 아이템
- 출현 토스트 메시지
- 처치 토스트 메시지
- 디스폰 토스트 메시지

## 숫자/상수/공식
- 알림 설정 최대 4개
- 알림 출력 시점: 보스 스폰 5분 전
- 남은 시간 1일 이상: [00일 00시간] 표기
- 남은 시간 1일 미만: [00시간 00분] 표기
- 남은 시간 5분 미만: [00분 00초] 표기
- 출현 중 몬스터 시간 표기: 00:00 (퇴장까지 남은 시간 카운트다운)

## 참조 시스템
- Monster.xlsx
- SpawnType (Scheduled)
- 보스 스케쥴 시스템

## 주요 섹션
- UI 작업 내역
- UI FLOW
- HUD
- 보스 몬스터 정보 - 네임드 몬터
- 네임드 몬스터 UI
- 보스 몬스터 상세 정보 - 월드맵
- 보스 몬스터 출현과 처치
- 보상
