# 변신창 조작 및 기능 대응 (요약)

> 출처: Confluence / PK
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/변신/변신창 조작 및 기능 대응/content.md

## 한 줄 설명
변신 메뉴 진입 시 캐릭터 외형을 고품질로 출력하고 유저가 회전/줌 조작으로 자유롭게 감상할 수 있도록 하는 변신창의 UI/카메라 시스템 및 기능 명세.

## 핵심 용어
- 변신창
- 변신용 맵
- 렌더링 Off 처리
- 그라데이션 배경
- Rim Light
- Idle 모션
- 교체 연출
- 카메라 시스템
- 줌 인/줌 아웃
- 캐릭터 회전
- Default_Offset
- ZoomIn_Offset
- ZoomOut_Offset
- Default_Distance
- ZoomIn_Distance
- ZoomOut_Distance
- FOV
- Zoom_Sensitivity
- Rotate_Sensitivity
- 핀치 인/아웃
- 마우스 드래그
- 원 핑거 드래그
- 보간
- 360도 회전

## 숫자/상수/공식
- Default_Distance: int (변신 창 진입 시 기본 카메라 거리)
- ZoomIn_Distance: int (최대 줌 인 거리)
- ZoomOut_Distance: int (최대 줌 아웃 거리)
- FOV: float (카메라 FOV 제어)
- Zoom_Sensitivity: float (줌인/아웃 속도)
- Rotate_Sensitivity: float (캐릭터 회전 속도)
- Default_Offset: Vector (X, Y) (기본 카메라 위치)
- ZoomIn_Offset: Vector (X, Y) (최대 줌인 시 카메라 위치)
- ZoomOut_Offset: Vector (X, Y) (최대 줌 아웃 시 카메라 위치)
- 360도 지속 회전 가능
