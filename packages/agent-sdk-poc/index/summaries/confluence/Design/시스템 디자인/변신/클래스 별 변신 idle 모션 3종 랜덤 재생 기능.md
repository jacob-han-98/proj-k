# 클래스 별 변신 idle 모션 3종 랜덤 재생 기능 (요약)

> 출처: Confluence / Design/시스템 디자인/변신
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/변신/클래스 별 변신 idle 모션 3종 랜덤 재생 기능/content.md

## 한 줄 설명
변신 캐릭터 선택 시 클래스별로 지정된 3개의 idle 모션 중 1종을 무작위로 재생하여 변신창의 단조로움을 해소하는 기능.

## 핵심 용어
- idle 모션
- 변신창
- 클래스
- Asset 슬롯
- MetamorphClass 테이블
- AssetName 컬럼
- 랜덤 인덱스
- 캐릭터 모델 로딩
- 애니메이션 블랜드
- loop 재생
- 카메라 값 초기화
- 변신 슬롯
- 다른 직업 보기
- 타 클래스 변신
- 동일 슬롯 선택

## 숫자/상수/공식
- idle 모션 3종
- 균일한 확률 선정 (입력된 개수 내에서)
- 2개 입력 시: 각 50% 확률
