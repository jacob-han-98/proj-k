## 숫자/상수/공식
- 단위 환산: 100 = 1%
- 투사의 인장 레벨 1~50 성공 확률: 10000(1레벨) → 150(50레벨)
- 투사의 인장 소모 파편: 10(1레벨) → 500(50레벨), 5단위 증가
- 투사의 인장 소모 골드: 10,000(1레벨) → 500,000(50레벨), 10,000 단위 증가
- 수호의 인장 레벨 1~50 성공 확률: 10000(1레벨) → 150(50레벨)
- 수호의 인장 소모 파편: 10(1레벨) → 500(50레벨), 5단위 증가
- 수호의 인장 소모 골드: 10,000(1레벨) → 500,000(50레벨), 10,000 단위 증가
- 마법의 인장 레벨 1~50 성공 확률: 10000(1레벨) → 150(50레벨)
- 마법의 인장 소모 파편: 5(1레벨) → 250(50레벨), 5단위 증가
- 마법의 인장 소모 골드: 5,000(1레벨) → 250,000(50레벨), 5,000 단위 증가
- 패시브 버프 획득 확률: 1000 (모든 버프 동일)
- 패시브 버프 획득 레벨: 10, 20, 30, 40, 50 (5단계마다)
