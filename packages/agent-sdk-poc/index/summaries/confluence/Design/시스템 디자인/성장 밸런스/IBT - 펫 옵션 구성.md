## 한 줄 설명
Project K의 펫 시스템에서 사용되는 고유 옵션과 강화 옵션의 등급별, 공격타입별 수치 정의 문서.

## 핵심 용어
- 펫 옵션
- 고유 옵션
- 강화 옵션
- 등급 (일반, 고급, 희귀, 영웅, 전설)
- 공격타입 (Melee, Range, Magic)
- 정령_검 (Melee 펫)
- 정령_활 (Range 펫)
- 정령_지팡이 (Magic 펫)
- 근거리 공격력
- 원거리 공격력
- 마법 공격력
- 명중 (근거리, 원거리, 마법)
- 치명타 확률
- 최대 HP
- 최대 MP
- 이동 속도
- 공격 속도
- 스킬 속도
- 경험치 획득률
- 골드 획득률

## 숫자/상수/공식
- 단위 환산: 100 = 1%
- 일반 등급: 1~3개 옵션 (최대 1개 수치)
- 고급 등급: 2개 옵션 (각 1개 수치)
- 희귀 등급: 3개 옵션 (각 1개 수치)
- 영웅 등급: 4개 옵션 (각 1개 수치)
- 전설 등급: 5개 옵션 (각 1개 수치)
- 강화 단계: 1~10단계
- 강화 1단계: 모든 공격력 +2
- 강화 10단계: 모든 공격력 +20, 모든 명중 +16, 모든 방어력 +12, 최대 HP +1000, 모든 피해 +300
