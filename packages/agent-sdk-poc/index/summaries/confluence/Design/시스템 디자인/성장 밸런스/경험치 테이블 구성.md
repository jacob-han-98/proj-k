# 경험치 테이블 구성 (요약)

> 출처: Confluence / 경험치 테이블 구성
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 밸런스/경험치 테이블 구성/content.md

## 한 줄 설명
릴리즈 버전까지 사용될 표준화된 경험치 성장 곡선을 정의하고, 플레이어 타입·콘텐츠 조합별 레벨업 시간을 시뮬레이션하는 테이블 구성 문서.

## 핵심 용어
- 경험치 테이블
- 성장 곡선
- 레버 기반 밸런싱
- Player Config
- ExpPerHour Config
- Dungeon Config
- Quest Config
- Daily Config
- Level-Exp
- 누적 플레이 타임 시뮬레이션
- Level Design-Level
- Tier
- Exponential growth
- 기본 경험치
- 추가 경험치
- 플레이어 타입 (캐주얼, 상위 10%, 상위 1%)
- 과금 분류 (무과금, 소과금, 중과금, 대과금)
- 입장/퇴장 레벨

## 숫자/상수/공식
- 플레이어 타입: 3가지 (캐주얼, 상위 10%, 상위 1%)
- 과금 분류: 4가지 (무과금, 소과금, 중과금, 대과금)
- 플레이어 타입 x 과금 타입 조합: 6개월 후 달성 레벨 산정
- Exponential growth: base exp, growth rate 설정
