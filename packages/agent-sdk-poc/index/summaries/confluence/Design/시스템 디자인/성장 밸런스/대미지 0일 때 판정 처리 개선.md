# 대미지 0일 때 판정 처리 개선 (요약)

> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 밸런스/대미지 0일 때 판정 처리 개선/content.md

## 한 줄 설명
대미지가 0인 상황에서의 전투 판정 처리 방식을 개선하여, 명중과 회피를 시각적으로 구분하고 CC 처리 규칙을 일관성 있게 정의하는 기획.

## 핵심 용어
- 대미지 0 판정
- 회피 (Evade)
- 스킬 회피
- 명중 판정 (Hit Chance)
- 최종 대미지
- CC (Crowd Control)
- Block
- Critical Hit
- Miss
- Guard
- 피격 액션
- VFX (Visual Effects)
- SFX (Sound Effects)
- 경직
- 스턴
- 귀환 불가
- 물약 사용 불가
- 판정 전 연출
- 판정 후 연출

## 숫자/상수/공식
- 대미지 최소값: 1 (대미지 0 이하 판정 시 1로 변경)
- 판정 순서: Hit Chance → Damage 계산 → Block/CC/Crit 판단

## 참조 시스템
