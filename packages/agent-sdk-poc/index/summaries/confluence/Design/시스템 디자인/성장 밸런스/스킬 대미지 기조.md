## 한 줄 설명
전투 중 평타와 스킬의 시간 비중(60:40)을 기반으로 스킬 쿨타임, 마나 소모, 대미지 배수를 설정하는 밸런싱 기조 및 계산 방법론을 정의한다.

## 핵심 용어
- 평타 (Normal Attack)
- 스킬 (Skill)
- 시간 비중 (Time Ratio)
- 쿨타임 (Cooldown)
- 시전 시간 (Cast Time)
- 마나 (Mana)
- 마나 회복량 (Mana Recovery)
- 스킬 등급 (Skill Grade)
- 일반 (Common)
- 고급 (Advanced)
- 희귀 (Rare)
- 영웅 (Heroic)
- DPS (Damage Per Second)
- 누킹 (Nuking)
- 유틸성 (Utility)
- 임팩트 (Impact)
- 효율 (Efficiency)
- 대미지 배수 (Damage Multiplier)
- 시뮬레이션 (Simulation)
- 선택과 마나 운영 (Skill Selection & Mana Management)

## 숫자/상수/공식
- 평타:스킬 시간 비중 = 6:4 (60:40)
- 기준 전투 시간 = 100초
- 평타 주기 = 1.5초
- 평타 시전 시간 = 0.5초
- 평타 시간 배분 = 33초
- 스킬 시간 배분 = 22초
- 일반 등급 스킬 쿨타임 = 30초 (100초 내 6.6회 등장)
- 고급 등급 스킬 쿨타임 = 45초 (100초 내 6.6회 등장)
- 희귀 등급 스킬 쿨타임 = 60초 (100초 내 6.6회 등장)
- 영웅 등급 스킬 쿨타임 = 180초 (100초 내 0회 등장)
- 스킬 시전 시간 = 1초 (기본 가정)
- 시전 시간 배수 증가 시 쿨타임 = Linear Scaling (Additive 아님)
- 평타 대비 대미지 배수 범위 = 1.5~4.5배
- 평타 대비 순간 대미지 배수 = 3~4배 (체감 임팩트)
- 평타 대미지 기준 = 몬스터 6타 사망 밸런스
- 평타 대비 대미지 배수 수식 = Base + 쿨타임 계수 × (스킬 쿨타임 / 평타 주기) + 마나 소모량 계수 × 마나 소모량
