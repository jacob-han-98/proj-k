# 스탯 리스트 (요약)

> 출처: Confluence / PK 공간
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 밸런스/스탯 리스트/content.md

## 한 줄 설명
Project K의 모든 플레이어 캐릭터 스탯을 정의하는 전체 리스트로, 공격, 방어, 상태이상, 회복, 획득 관련 스탯을 포함한다.

## 핵심 용어
- Attack (공격력)
- AttackSpeed (공격 속도)
- SkillSpeed (스킬 시전 속도)
- AllAccuracy (명중)
- CriticalChance (치명타 확률)
- CriticalDamage (치명타 대미지)
- AllDamage (모든 대미지)
- MeleeDamage (근접 대미지)
- RangeDamage (원거리 대미지)
- MagicDamage (마법 대미지)
- PvpAllDamage (PvP 모든 대미지)
- Defence (방어력)
- AllEvade (회피)
- AllGuard (막기)
- CcAllResist (상태이상 저항)
- CcTimeReduction (상태이상 지속 시간 감소)
- MaxHp (최대 HP)
- MaxMp (최대 MP)
- MoveSpeed (이동 속도)
- RegenHp (HP 자연 회복량)
- ExpAdd (경험치 추가 획득)
- GoldAdd (골드 추가 획득)
