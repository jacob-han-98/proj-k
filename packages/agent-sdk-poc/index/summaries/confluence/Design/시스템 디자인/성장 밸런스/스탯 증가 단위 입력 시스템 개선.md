# 스탯 증가 단위 입력 시스템 개선 (요약)

> 출처: Confluence / Design > 시스템 디자인 > 성장 밸런스 > 스탯 증가 단위 입력 시스템 개선
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 밸런스/스탯 증가 단위 입력 시스템 개선/content.md

## 한 줄 설명
기존 정수 기반 ValuePerPoint 방식을 개선하여 비정수 비율의 스탯 증가(예: 5포인트당 2스탯)를 직관적으로 설정할 수 있도록 하는 시스템 개선안.

## 핵심 용어
- ValuePerPoint
- NumberOfPoints
- StatClass.xlsx
- 스탯 증가 단위
- 포인트
- 성장 비율
- 밸런스 조정
- int32
- 정수 입력
- 비율 표현

## 숫자/상수/공식
- 스탯 = int( 찍은 포인트 / NumberOfPoints ) * ValuePerPoint
- 예시: 5포인트당 2스탯 (NumberOfPoints=5, ValuePerPoint=2)
- int(1/5) * 2 = 0
- int(5/5) * 2 = 2
- int(10/5) * 2 = 4
