# 아이템 등급 차별화 기조 (요약)

> 출처: Confluence / Design/시스템 디자인/성장 밸런스/아이템 등급 차별화 기조
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 밸런스/아이템 등급 차별화 기조/content.md

## 한 줄 설명
레벨 구간별 기준 등급을 설정하고 표준 밸런스에서 가산/감산으로만 등급을 차별화하여 콘텐츠 난이도를 안정화하고 밸런스 유지보수를 용이하게 하는 기조.

## 핵심 용어
- 표준 밸런스
- 레벨 구간
- 기준 등급
- Common
- Uncommon
- Rare
- Unique
- Legendary
- Myth
- 단계
- 고정 보너스 스탯
- 파워 스파이크
- 장비 자동 생성
- 가산/감산
- 배율

## 숫자/상수/공식
- 레벨 1-10: Common 기준 등급
- 레벨 11-30: Uncommon 기준 등급
- 레벨 31-50: Rare 기준 등급
- 레벨 51-100: Unique 기준 등급
- 정수형 스탯(공격/방어/HP): +1을 1단계
- 비율형 스탯(확률/속도): 0.1%를 1단계
- Common 기준 등급 시 Uncommon과 +1 차이
- Uncommon 기준 등급 시 Common -1, Rare +1 차이
- Rare 기준 등급 시 Uncommon -1, Unique +1 차이
- Unique 기준 등급 시 Rare -1, Legendary +1, Myth +2 차이

## 참조 시스템
- PK_성장 밸런스.xlsm (장비 자동 생성 시트)

## 주요 섹션
- 기획 의도 및 목적
- 기조
- 기본 개념
- 표준 밸런스
- 레벨 구간과 기준 등급
- 단계
- 등급 간 기본 차이
- 상위 등급의 고정/랜덤 보너스
