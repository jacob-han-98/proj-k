# [개인 성장] 승천의 인장 (요약)

> 출처: PK / Design/시스템 디자인/성장 컨텐츠
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 컨텐츠/[개인 성장] 승천의 인장/content.md

## 한 줄 설명
캐릭터가 1단계부터 50단계까지 일직선으로 순차 강화하여 능력치를 얻는 선형 성장 시스템으로, 실패 페널티 없이 기적의 재시도와 특별 구간 무작위 버프를 통해 성장 쾌감을 극대화한다.

## 핵심 용어
- 승천의 인장
- 인장 탭
- 인장의 파편
- 찬란한 인장의 정수
- 특별 구간 (10, 20, 30, 40, 50단계)
- 기적의 재시도
- 무작위 버프
- 버프 풀 (Pool)
- 버프 재설정
- 특별 인장 효과 슬롯
- 석판 노드
- 성공 확률
- 누적 능력치
- 강화 정보
- 소모 재화
- 최대 레벨 (50단계)
- 해금 조건
- 2단계 점프
- 버프 레벨 (중복 합산)

## 숫자/상수/공식
- 최대 단계: 50단계
- 특별 구간: 10, 20, 30, 40, 50단계
- 기적의 재시도 확률: 약 5% (예시)
- 2단계 점프 확률: 약 0.1% (예시)
- 성공 확률 기준: 10000분율 (10000 = 100%)
- 인장의 파편 최대 중첩: 9,999개
- 찬란한 인장의 정수 최대 중첩: 9,999개
- 특별 인장 효과 슬롯: 5개
- 난수 생성 범위: 1~10000
