## 한 줄 설명
승천의 인장 시스템의 UI 사용성 향상을 위한 폴리싱 제안 문서로, 단계 강화, 인장 획득, 버프 시스템의 전체 UI 구조와 상호작용 방식을 정의한다.

## 핵심 용어

- 단계 강화

- 인장
- 버프
- 인장 교체

## 숫자/상수/공식
- 10단계 강화 구간마다 인장 획득
- 강화 능력치 최대 5개
- 강화 능력치 종류 16종
- 단계는 0에서 시작
- 인장 교체 확률 = 기존 인장 획득 확률과 동일
