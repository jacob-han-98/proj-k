## 숫자/상수/공식
- 기본 해금 슬롯: 1~2개
- 총 거인 부위 항목: 7개 (왼쪽 눈, 왼쪽 귀, 빈 머리, 코, 입, 오른쪽 눈, 오른쪽 귀)
- BM 추가슬롯 해금: 최대 2~3개 (폐기된 안)
