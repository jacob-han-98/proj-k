# 거인의 유산 시스템 (요약)

> 출처: Confluence / PK 공간
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 컨텐츠/거인의 유산 시스템/content.md

## 한 줄 설명
거인의 머리 부위를 테마로 한 횡적 성장 컨텐츠로, 확률 기반 랜덤 능력치 획득을 통해 재화 순환과 성장감을 제공하는 시스템.

## 핵심 용어
- 거인의 유산 시스템
- 1뎁스 (항목: 거인의 부위)
- 2뎁스 (단계: 1~10단계)
- 3뎁스 (능력치 슬롯: 3개)
- 리프 정착
- 거인의 피
- 능력치 등급 (일반, 고급, 희귀, 영웅, 전설, 신화)
- 능력치 카테고리 (공격력 스탯, 방어력 스탯, 유틸 스탯)
- 해금 조건
- 슬롯 잠금 (고정)
- BM 다이아
- 골드
- 코인
- 확률업 아이템
- 메인 퀘스트
- 캐릭터 레벨

## 숫자/상수/공식
- 총 항목 수: 7개 (왼쪽 눈, 오른쪽 눈, 왼쪽 귀, 오른쪽 귀, 코, 입, 머리)
- 2뎁스 단계: 1~10단계
- 3뎁스 슬롯: 3개
- 전체 획득 능력치 칸수: 7 × 10 × 3 = 210개
- 능력치 획득 시 3개 슬롯 동시 획득
- 이펙트 지속 시간: 1.5~2초 이내
- 슬롯 고정 비용: 등급별로 개별 지정 (테이블 입력)
- 필수 재화 소모: 골드 + 코인 (모두 필수)
- 선택 재화: 거인의 피 (확률업), BM 다이아 (슬롯 고정)

## 참조 시스템
- 서버탐험 시스템 (코인 획득 출처)
- 메인 퀘스트 시스템 (1뎁스 해금 조건)
- 캐릭터 레벨 시스템 (2뎁스 해금 조건)
- 기존 스탯/능력치 시스템
- 인벤토리 시스템 (거인의 피 아이템 소지)
