## 한 줄 설명
메인퀘스트 진행에 따른 지역 단위로 제공되는 3가지 개별과제(필드사냥, 일일퀘스트, 보스공략)를 통해 재료를 획득하고 등록하여 단계적으로 능력치를 성장시키는 횡적 성장 컨텐츠.

## 숫자/상수/공식
- 개별과제 3가지 (필드사냥, 일일퀘스트, 보스공략)
- 단계: 1~8단계 (확장 가능성)
- 각 단계 내 하위 달성항목: 총 30개 (예정)
- 각성: 3개 순차 진행 (제1각성, 제2각성, 제3각성)
- 각성 도달 지점: 10개 완성마다 각 각성 도달 (10단계, 20단계, 30단계)
- 진행도 계산: 현재 진행중인 하위단계/총 하위단계 × 100 (정수 표현)

## 참조 시스템
- 거인의 유산 시스템 (능력치 테이블 구조 동일 적용 가능)
- 메인퀘스트 시스템 (지역 해금 조건)
- 필드사냥 컨텐츠
- 일일퀘스트 컨텐츠
- 레이드보스 컨텐츠
