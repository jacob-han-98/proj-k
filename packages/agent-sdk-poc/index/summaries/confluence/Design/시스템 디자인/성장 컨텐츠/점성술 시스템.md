# 점성술 시스템 (요약)

> 출처: Confluence / 점성술 시스템
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/성장 컨텐츠/점성술 시스템/content.md

## 한 줄 설명
각 계절별 황도궁 별자리 성흔을 장착하여 개별/세트 효과 능력치를 얻는 성장 컨텐츠 시스템으로, 확률/조합/강화 형태의 성장과 장착/강화/교체를 고민하는 구조를 제공한다.

## 핵심 용어
- 성흔(Stigma)
- 황도궁
- 별자리
- 카테고리(봄/여름/가을/겨울)
- 세트 효과
- 등급(일반/고급/희귀/영웅/전설)
- 합성
- 프리셋
- 추천 장착
- 슬롯(총 20슬롯, 카테고리당 5슬롯)
- 오망성
- 암거래 시스템
- 거래소
- 인벤토리
- 필터링
- 자동 등록
- 자동 합성
- 뽑기(소환)
- 슬롯 강화
- 세공석

## 숫자/상수/공식
- 카테고리별 슬롯: 5개 (총 20슬롯)
- 프리셋: 최대 3개 (SET.1, SET.2, SET.3)
- 합성 조건: 동일 카테고리&등급 성흔 5개 투입
- 합성 결과 개수: 5배수마다 1개 추가 (X1~X11)
- 최대 등록 개수: 110개
- 봄 오픈 레벨: 40
- 여름 오픈 레벨: 50
- 가을 오픈 레벨: 60
- 겨울 오픈 레벨: 70
- 확률 단위: 100만분의 1
- 세트 효과 조건: 같은 등급 2개 이상 또는 같은 별자리 2개 이상

- UI 및 기능 설명 (진입 버튼, 성흔 UI, 부분별 상세 설명, 성흔 세부 UI, 합성 UI)
