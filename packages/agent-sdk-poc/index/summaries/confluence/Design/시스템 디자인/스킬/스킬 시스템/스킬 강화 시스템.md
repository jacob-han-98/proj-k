# 스킬 강화 시스템 (요약)

> 출처: PK / 스킬 강화 시스템
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/스킬/스킬 시스템/스킬 강화 시스템/content.md

## 한 줄 설명
습득한 스킬을 재화와 재료를 소모하여 레벨을 강화하는 시스템으로, 등급과 레벨에 따라 성공/실패/단계 하락의 확률 기반 결과가 결정되며 자동 강화 기능을 지원한다.

## 핵심 용어
- 스킬 강화
- 강화 레벨
- 강화 성공 확률
- 강화 단계 하락 확률
- 강화 유지 확률
- 스킬 등급 (일반, 고급, 희귀, 영웅, 전설)
- 강화 재료
- 자동 강화
- 목표 단계
- 궁극기 강화
- 모체 스킬 (MotherSkill)
- 스킬 ID 규칙
- 재료 대체
- 강화 연출
- 스킬 초월 (추후 업데이트)
- SkillEnchantClass
- SkillEnchantItemClass
- 안전 강화
- 단계 하락

## 숫자/상수/공식
- 스킬 레벨 기본값: 0
- 강화 결과 종류: 3가지 (성공, 실패, 단계 하락)
- 확률 계산식: 10000(만분율) - 강화 성공확률+@ - 강화 단계 하락 확률+@ = 강화 유지 확률
- 예외 처리: 강화 유지 확률이 0 미만일 경우 0으로 처리, 강화 성공확률 = 10000 - 강화 단계 하락 확률
- 일반 등급: 레벨 1~5 (레벨 5부터 단계 하락 확률 50%)
- 고급 등급: 레벨 1~5 (레벨 5부터 단계 하락 확률 50%)
- 희귀 등급: 레벨 1~5 (레벨 4부터 단계 하락 확률 30%, 레벨 5는 50%)
- 영웅 등급: 레벨 1~5 (레벨 3부터 단계 하락 확률 15%)
- 전설 등급: 레벨 1~5 (레벨 2부터 단계 하락 확률 5%, 레벨 5는 59%)
- 자동 강화 목표 단계: 5/10/15 단계 (스킬 등급에 따라 구분)
- 스킬 초월: 최대 10회 시도 가능
- 클래스 코드: 90(All), 10(가디언), 20(워리어), 30(아처), 40(아바레스트), 50(매지션), 60(샤먼)
