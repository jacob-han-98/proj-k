## 한 줄 설명
기존 변신 종속 스킬 구조를 클래스 종속 구조로 변경하며, 클래스 전용 스킬, 공용 스킬, 변신 고유 효과로 구성하는 새로운 스킬 시스템 설계.

## 핵심 용어
- 클래스 (Class)
- 변신 (Metamorph)
- 스킬 (Skill)
- 공용 스킬 (Common Skill)
- 클래스 전용 스킬 (Class Skill)
- 변신 고유 효과 (Metamorph-specific Effect)
- CharacterSkillClass 테이블
- MetamorphClass 테이블
- SkillGroupId_Common
- SkillGroupId_Class
- ClassId 컬럼
- HUD 스킬 슬롯
- 평타 (Attack)
- BaseMetamorph
- 애니메이션 리소스 (AnimationResource)
- 발동 액션 (Invoke)
- 스킬창 (Skill UI)
- 터치&드롭 (Touch & Drag)

## 숫자/상수/공식
- 공용 스킬 ClassId = "0"
- 클래스 스킬 ClassId = CharacterClass - Id
- HUD 스킬 슬롯 자동 등록 순서 = 1 → 4번 순
- "New" 마크 출력 조건: 스킬 획득 후 15분 이내 AND 스킬 획득 후 스킬창 최초 오픈
- 전설 등급 이상 고유 애니메이션: Idle_P / Idle_B / Run_P / Run_B / Attack_01 / Attack_02 / Ultimate
- 공통 애니메이션 Attack01 재생 시간 = 1.5초, Hit 타이밍 = 1.2초
