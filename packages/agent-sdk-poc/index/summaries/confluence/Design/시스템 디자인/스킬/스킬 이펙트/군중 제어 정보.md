## 한 줄 설명
대상의 이동, 공격, 스킬 사용, 아이템 사용 등을 제어하는 상태 이상의 정의, 규칙, 타입 분류 및 적용 메커니즘을 정의한 문서.

## 핵심 용어
- 군중 제어 (CC)
- CcEnum
- CcType
- BonusEnum
- BuffClass
- BuffOverlapRule
- Channel
- Grade
- MaxCount
- IgnoreSameRule
- 기절 (Stun)
- 속박 (Hold)
- 침묵 (Silence)
- 당겨오기 (Pull)
- 밀쳐내기 (Push)
- 둔화 (Slow)
- 경직 (Stiff)
- Debuff
- 면역 상태
- 상태 이상 적중 판정
- 상태 이상 저항 스탯

## 숫자/상수/공식
- CcEnum Value: None(0), Debuff(1), Stun(2), Hold(3), Silence(4), Pull(5), Push(6), Slow(7), Stiff(8)
- Pull/Push 적용 시간: 1초 이하
- Stiff(경직): 치명타 시 100% 발동, 이때 적중/저항 스탯 영향 받지 않음
- 상태 이상 공식: 문서 내 이미지 참조
- 면역 우선 순위: 상태 이상 최종 적중 판정보다 높음

## 참조 시스템

- StatClass - "Stat" 컬럼

- CharacterSkillClass
- MonsterSkillClass
