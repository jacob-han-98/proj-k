## 한 줄 설명
자신 또는 상대의 HP, MP, 거리, 보호막 상태 등을 조건으로 검사하여 조건을 만족할 때 효과를 부여하는 시스템을 정의한다.

## 핵심 용어
- BattleCondition
- BattleEntity
- HpPercent
- MpPercent
- Distance
- HasBarrier
- Self
- Other
- Operator
- BuffClass
- EffectClass
- Target
- Type
- Value
- Comparer
- 조건부 효과
- 보호막
- 추가 피해 버프
- 밀치기 스킬

## 숫자/상수/공식
- 10000 => 100% (HP % 및 MP % 입력 단위)
- 100 => 1m (거리 입력 단위)
- 0 = 보호막 없음, 1 = 보호막 있음 (HasBarrier 값)
- HP 70% 이상 (버프 [4005] 조건)
- 추가 피해 +1000 (이펙트 [4006] 효과)
- 6M 이내 거리 (버프 [4021] 조건)
- 100% 확률 (버프 [4021] 발동 확률)
