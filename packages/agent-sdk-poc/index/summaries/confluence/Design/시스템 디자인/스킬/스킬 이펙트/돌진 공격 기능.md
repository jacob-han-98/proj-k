# 돌진 공격 기능 (요약)

> 출처: Confluence / Design/시스템 디자인/스킬/스킬 이펙트/돌진 공격 기능
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/스킬/스킬 이펙트/돌진 공격 기능/content.md

## 한 줄 설명
시전자가 대상에게 순간 이동 후 공격하는 돌진 스킬의 동작 방식, 시전 조건, 도착 지점 우선순위, 테이블 구조를 정의한 기능 명세서.

## 핵심 용어
- 돌진 스킬
- 순간 이동
- CombatZoneType
- 배경 프랍
- 실린더
- SkillCategoryEnum
- Dash
- 장애물 체크
- 도착 위치 우선순위
- 시전 조건
- 타겟
- 시전자
- 텍스트키
- CharacterSkillClass
- MonsterSkillClass
- Options 컬럼
- 카메라 이동 딜레이
- 충돌체

## 숫자/상수/공식
- CombatZoneType: Normal, Safety Chaotic, Town (Town 제외 전투 가능)
- 8방향 장애물 체크
- 카메라 이동 딜레이 입력값 1000 = 1초
- 시전자와 타겟 간 거리값(cm) 입력 가능
- 입력값 0 또는 공란 = 실린더와 실린더가 맞닿는 위치까지 이동

## 참조 시스템
- (없음)

## 주요 섹션
- 정의 및 배경
- 규칙
- 동작 방식
- 기존 스킬과 돌진 스킬의 차이
- 세부 규칙
- 스킬 시전 조건
- 이동 후 도착 지점 우선순위
- 텍스트키 정보
- 기타 사항
- 테이블 구조
- CharacterSkillClass / MonsterSkillClass
