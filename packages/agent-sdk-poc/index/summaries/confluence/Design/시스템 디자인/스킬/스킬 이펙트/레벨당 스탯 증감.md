## 한 줄 설명
대상의 레벨 증감에 따라 특정 스탯 효과가 자동으로 가감되는 기능으로, 패시브 스킬 등에서 자연스러운 성장 효과를 제공하고 밸런스 디자인 편의성을 높인다.

## 핵심 용어
- EffectCategoryEnum
- LevelCheck
- BonusEnum
- BaseLevel
- PerLevel
- MaxLevel
- BaseValue
- 조건 Enum
- 레벨 조건
- 상승량
- 패시브 스킬
- BuffClass
- EffectId
- 레벨 다운
- 서버 에러

## 숫자/상수/공식
- 조건 Enum 4종 (BaseLevel, PerLevel, MaxLevel, BaseValue)
- 이펙트 입력칸 5개 (2025.07.30 기준)
- 조건 Enum 4종 + 기본 효과 1개 = 최대 5개 입력 필드
- 각 데이터당 최대 1개 효과 연결 가능
