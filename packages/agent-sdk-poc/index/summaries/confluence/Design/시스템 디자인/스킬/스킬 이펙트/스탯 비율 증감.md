## 한 줄 설명
스탯을 절대값이 아닌 비율로 증감시키는 기능으로, 기존 Normal 카테고리의 증감 방식과 유사하게 동작한다.

## 핵심 용어
- 스탯 비율 증감
- EffectClass
- EffectCategory
- StatIncreaseRate
- BonusEnum
- Normal 카테고리
- 절대값
- 비율
- 소수점 버림 처리
- Effect1~5
- Value1~5
- 회피
- 공격력

## 숫자/상수/공식
- 기존 스탯 + 기존스탯 * 비율 = 최종 값
- -10000 = -100%
- 1000 = 10%
- 0 = 동작 하지 않음
