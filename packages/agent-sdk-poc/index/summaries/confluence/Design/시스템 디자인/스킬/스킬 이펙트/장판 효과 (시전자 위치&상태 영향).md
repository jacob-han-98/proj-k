## 한 줄 설명
시전자의 사망 또는 범위 이탈 시 즉시 제거되는 장판 효과의 정의 및 구현 규칙. 기존 PulseAreaAttack에 시전자 상태 연동 기능을 추가한 개량 버전.

## 숫자/상수/공식
- 버프 적용/해제 오차: 최대 0.5초
- 틱 주기: 약 0.5초 (권장)
- BuffId Duration (범위 진입/이탈 방식): -1 (무제한)
- 조건: 틱당 시간 ≤ 최대 출력 시간
