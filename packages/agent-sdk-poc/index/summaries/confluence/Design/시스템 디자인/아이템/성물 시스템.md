## 한 줄 설명
Project K의 성물 시스템은 오딘/뱀피르와 유사한 방식의 장신구 장비로, 파츠 기반 강화 및 프리셋 관리 기능을 제공하는 엔드게임 콘텐츠 시스템이다.

## 핵심 용어
- 성물(HolyRelic)
- 파츠(Brooch, Pendant, Bracelet, Talisman, Armband, Crest, Badge, Epaulette)
- 유일(Epic) 등급
- 강화(Enchant)
- 명중(Hit)
- 확률형 스탯(EchantRandom)
- 장비 프리셋(Equipment Preset)
- 자동 장착(Auto Equip)
- 세공(Crafting)
- 공명(Resonance)
- 저주받은 주문서(Cursed Enchant)
- 전투력(Combat Power)
- 파괴 위험(Destruction Risk)
- ExpireTime(유효 기간)
- 인벤토리 슬롯
- 장착 알림(Equipment Notify)
- 모두 해제(Unequip All)

## 숫자/상수/공식
- 최초 4파츠 개방, 최대 8파츠까지 제공
- 명중: +1강 마다 명중 +1 증가
- 특별 스탯 추가: +4강, +8강, +12강 마다 확률형 능력치 추가
- +2강부터 파괴 위험 있음
- EquipmentNotifyLifeTime = 10초
- 장비 프리셋 최대 2개 기본 제공
- 프리셋 변경 재사용 대기 시간: 0.5초
- 자동 장착/모두 해제 공통 재사용 대기 시간: 0.1초
- 인벤토리 초과 시 표시 예시: 100/80
- 우편 보관 기간: 7일
- 확률 입력 단위: 백만분율(Prob)
