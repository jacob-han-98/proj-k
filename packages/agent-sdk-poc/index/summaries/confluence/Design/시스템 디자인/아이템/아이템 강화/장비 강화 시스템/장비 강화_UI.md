## 숫자/상수/공식
- SuccessProb = 100% (안전 강화 구간 판정)
- 연출 시간: 총 길이 최대 3초
- 1초 정도 장비 아이콘 반짝임 연출 (안전 강화)
- 강화 비용: Enchant > GoldPrice
