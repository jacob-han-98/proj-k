## 한 줄 설명
플레이어가 인벤토리의 아이템을 분해하여 재료를 획득하는 UI 시스템으로, 개별/일괄 분해 모드, 예상 결과 확인, 최종 분해 결과 화면으로 구성된다.

## 핵심 용어
- 아이템 분해
- 분해 모드
- 개별 분해 버튼
- 일괄 분해 버튼
- 분해 목록
- 등급 필터
- 확정 보상
- 확률 보상
- DismantleFix
- DismantleRandom
- 예상 분해 결과 UI
- 최종 분해 결과 UI
- 인벤토리 슬롯
- 잠금 상태 아이템
- 일반/고급/희귀 등급
- 분해의 가루
- 시스템 메시지

## 숫자/상수/공식
- 확정 보상 리스트 최대 출력: 3.5개
- 확률 보상 리스트 최대 출력: 3.5개
- 획득 보상 리스트 최대 출력: 6.5개
- 분해 결과 UI 닫기 불가 시간: 최초 2초
- 확률 보상 수량 계산: Prob < 100% 시 "0~(분해 개수*AmountMax)", Prob = 100% 시 "1~(분해 개수*AmountMax)"
- 기본 선택 등급 필터: 일반, 고급
