## 한 줄 설명
플레이어가 인벤토리의 장비 아이템을 분해하여 확정 보상과 확률 보상을 획득하는 시스템의 규칙 및 데이터 구조를 정의한다.

## 핵심 용어
- CanDismantle
- 분해 모드
- 가방 모드
- 확정 보상
- 랜덤 보상
- DismantleRewardId
- DismantleProbabilityRewardId
- DismantleReward
- DismantleProbabilityReward
- ItemEquipClass
- RewardType
- ItemId
- Amount
- Prob
- 강화 단계
- 아이템 툴팁 UI
- 등급 필터
- 미잠금 상태

## 숫자/상수/공식
- Prob 단위: 1,000,000 = 100%
- Prob 기본값: 1,000,000
- Amount 기본값: 1
- AmountMin 기본값: 1
- AmountMax 기본값: 1
- +0강 아이템만 자동 선택 대상
- 최대 분해 개수 제한: 없음

- 분해 성공 확률
- 분해 비용 및 기타
