## 한 줄 설명
잡화(소모품) 상인에게서 사전에 설정한 구매 품목과 개수를 한 번에 구매하는 기능을 정의한다.

## 핵심 용어
- 일괄 구매 설정
- 일괄 구매
- 잡화(소모품) 상인
- MerchantId
- MaxStack
- 계산기 팝업(WBP_Confirm_Calculator)
- 서포트 모드
- 자동 정비
- 소모품 원격 구매 설정
- HP 물약
- 물약 등급(일반, 고급, 희귀)
- 인벤토리
- 구매 가능 수량
- 물약 소지 개수 제한
- ContentSetting
- PurchaseBatchMerchantId
- 시스템 메시지
- Modal Popup

## 숫자/상수/공식
- 설정 수량 기본값: 0
- 수량 최대값: 해당 아이템의 MaxStack값
- 물약 자동 조정: 등급이 가장 높은 물약부터 개수를 채움
- 구매 금액 계산: 수량 × 아이템 가격의 합산
