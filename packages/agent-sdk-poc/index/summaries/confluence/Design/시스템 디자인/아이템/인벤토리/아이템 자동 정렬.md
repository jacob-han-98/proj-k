## 한 줄 설명
인벤토리에서 정렬 버튼 터치 시 규칙에 따라 아이템이 자동 정렬되는 기능으로, 장착 장비, 타입, 등급, 티어, 인덱스, 획득 시각 등의 우선순위를 적용한다.

## 숫자/상수/공식
- 우선순위 1~6 (기본 정렬 규칙)
- ItemTypeEnum 인덱스: Equip 1, Consume 2, Material 3, Quest 4, Dummy 5
- 쿨타임 단위: 3000 = 3초 (ContentSetting에서 설정)
