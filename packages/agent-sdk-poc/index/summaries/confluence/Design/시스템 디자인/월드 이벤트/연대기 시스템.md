# 연대기 시스템 (요약)

## 한 줄 설명
전체 서버의 타임라인을 기록하고 열람할 수 있는 역사 페이지로, 월드 이벤트 완료 시 서버 기록이 남으며 플레이어가 메뉴를 통해 접근하는 정보 시스템.

## 핵심 용어
- 연대기 시스템
- 프리시즌(PreSeason)
- 시즌N(반복)
- 월드 이벤트
- 공성전
- 인터서버 전장
- 명예의 전당
- 기록(실록)
- 서버 파워
- 이벤트 타입
- 전투력 성장
- 스킬 강화
- 장비 아이템 강화
- 정령의 탑 도전 단계
- 월드 보스 처치 경쟁
- 필드 보스 처치 경쟁
- 이벤트 몬스터 처치 경쟁
- ChronologyID
- Chronology 테이블
- ChronoloyReward 테이블

## 숫자/상수/공식
- 진입 조건: 캐릭터 레벨 Lv.20
- 초기 상태 적용 시점: 3주차부터
- 서버 파워 계산: 1등부터 100등까지 서버별 순위/가중치 합산 후 비율 표시
- 스크롤 이동 단위: 1주차씩

- 개요
- 규칙 (기본, 연대기 구성, 연대기 기록)

- 테이블 및 데이터 구조 (테이블 변경, 신규 테이블 추가)
