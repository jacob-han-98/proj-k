## 한 줄 설명
월드 이벤트 팝업에서 퀘스트 달성도와 보상 수령 상태를 시각적으로 구분하기 위한 UI/UX 개선 방안을 정의한 문서.

- 딤 처리 (Dimmed)
- 달성도

- 목표 횟수
- 게이지 바
- 보상 팝업
- 퀘스트 목록
- 이벤트 탭 버튼
- 개별 받기
- 모두 받기
- 토스트 팝업
- 랭킹 팝업
- 신규 이벤트
- 이펙트

- 가방 공간
- 순위 결정 시간
- 점수 및 순위 보상

## 숫자/상수/공식
- 달성도 표기: {시행 횟수}/{목표 횟수}
- 시행 횟수 ≤ 목표 횟수 (초과 불가)
- 가방 공간 기준: 100칸
- 토스트 팝업 최대 표시: 3개
- 랭킹 상위권: 1위~10위
- 랭킹 체크 주기: 5분
- 퀘스트 목록 표시: 3개 전체 + 4번째 반 표시
- 아이템 슬롯 길게 터치: 3초
