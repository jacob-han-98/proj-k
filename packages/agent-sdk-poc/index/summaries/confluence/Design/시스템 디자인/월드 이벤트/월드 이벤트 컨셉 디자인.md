## 한 줄 설명
서버 침공을 메인 테마로 한 Project K에서 시간의 흐름에 따라 순차적으로 진행되는 월드 이벤트 시스템의 인프라 구성 및 설계 방안을 정의하는 문서.

## 숫자/상수/공식
- 하루 최대 이벤트 개수: 10개
- 테스트용 이벤트: 2~3개
- 초기 서버 그룹 최소 개수: 3~5개
- 이벤트 분기 구간: 공성전 진입 전까지 1~2회
- 상점 종료 시기: 이벤트 종료 후 2~3일 이후
- 시간대 기준: GMT+9 (대한민국 표준 시간)
- 이벤트 시작/종료: 자정(0시)
