- Gold (인게임 기본 재화)
- 캐릭터 귀속
- 서버 귀속
- 길드 귀속

- CurrencyEnum
- DbEntityEnum
- Mileage
- Coin
- GuildCoin
- GuildFund
- MissionCoin
- InfiniteCoin
- BattleCoin
- HonorCoin
- RewardTypeEnum

## 숫자/상수/공식
- CurrencyEnum 값: Gold(1), Diamond(2), FreeDiamond(3), Mileage(4), Coin(5), GuildCoin(6), GuildFund(7), MissionCoin(8), InfiniteCoin(9), BattleCoin(10), HonorCoin(11)

- 재화 사용 순서: FreeDiamond → Diamond
