# 이동 명령 처리 관련 개선 (요약)

> 출처: Confluence / Design/시스템 디자인/전투/이동 명령 처리 관련 개선
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/전투/이동 명령 처리 관련 개선/content.md

## 한 줄 설명
PC 기본 조작 및 이동 관련 베이스 규칙을 확인하고, 현재 빌드에서 베이스 규칙과 상반되거나 어색한 이동 조작 처리를 개선하여 플레이어 몰입도를 유지하는 방안을 정의한다.

## 핵심 용어
- 이동 명령
- 자동 이동
- 직접 제어 이동
- 방향키 WASD
- 퀘스트 모드 (Quest 모드)
- 자동 모드 (Auto 모드)
- 퀵이동
- 월드맵 자동 이동
- NPC 더블 클릭
- 자동 전투
- 조작 입력
- 이동 불가 상태
- 시스템 메시지
- 네비메쉬
- 슬라이딩 이동
- 군중 제어 (C.C)
- 컷신
- UI 호출
- 최신 입력 조작 우선시

## 숫자/상수/공식
- 250709 빌드 기준
- SystemMsg ID 9,003 (자동 이동 종료 메시지)
- PC 한 번에 처리하는 이동 명령: 1개로 제한
- 방향키 중복 입력: 2~4개 가능 (방향 조절용)

- (없음)

## 주요 섹션
- 기획 의도 및 목적
- 현재 빌드 내 개선 필요점
  - (중요도 중) 특정 자동 이동 진행 중 새로운 이동 관련 처리
  - (중요도 중) 자동 이동 비활성화 후 PC 이동이 지속되는 건
  - (중요도 하) NPC와 상호 작용 UI 호출 중 PC 이동이 가능한 건
- 참고용) 기획적 방향성
  - 이동 조작의 입력과 실행 처리
  - 이동 진행 중 새로운 이동 조작 발생 시
  - 경우에 따른 베이스 규칙 처리 예시
