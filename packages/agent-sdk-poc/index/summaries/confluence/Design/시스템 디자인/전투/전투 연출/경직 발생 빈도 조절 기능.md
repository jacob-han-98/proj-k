## 한 줄 설명
PvE 몬스터의 피격 연출 재생 여부와 확률을 제어하는 기능으로, 일반 몬스터와 보스/네임드 몬스터를 구분하여 적용한다.

## 핵심 용어
- PvE 몬스터
- NPC
- 피격 연출
- 피격 모션
- 연출 Only
- 클라이언트 판정
- 서버 판정
- 네임드 몬스터
- 보스 몬스터
- 일반 몬스터
- Combat-idle
- 전투 아이들
- 기본 공격
- 평타
- 레이드 몹
- 특수 케이스

## 숫자/상수/공식
- DisableHitReaction: 0 (피격 연출 우선 순위 기본값)
- DisableHitReaction: 1 (피격 연출 재생 X)
- HitReactionRate: 50 (피격 연출 확률 기본값, 0~100%)
