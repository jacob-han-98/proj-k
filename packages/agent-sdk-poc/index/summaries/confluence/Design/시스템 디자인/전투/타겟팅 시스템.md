## 숫자/상수/공식
- HUD 타겟 정보 동시 출력 최대 개수: 1개
- 네임 플레이트 동시 출력 최대 개수: 2개
- 상태이상 아이콘 최대 출력 개수: 15개
- 상태이상 아이콘 16개째부터: +1로 표시
- HP 감소 애니메이션 연출 시간: 0.2초
- HP바 줄 개수 계산: MaxHp를 MonsterClass - MaxHpGauge로 나눈 값 (소숫점 강제 올림)
- 나를 공격 중인 대상 UI 해제 조건: 마지막 피해 이후 5초 간 추가 피해 없음 또는 30m 이상 거리 벌어짐
