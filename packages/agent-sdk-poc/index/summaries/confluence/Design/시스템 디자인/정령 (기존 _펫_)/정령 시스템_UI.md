## 한 줄 설명
Project K의 정령 시스템에 대한 UI 설계 문서로, 정령 목록, 합성, 강화, 도깨비 탭 및 HUD 정보 UI와 신규 아이콘을 정의한다.

## 핵심 용어
- 정령
- 도깨비
- 근/원/마 심볼 (Melee/Range/Magic)
- 강화 단계
- 합성
- 안전 강화
- 확률 강화
- PetClass
- AttackType
- PetType
- PetGradeInfo
- MaxEnchantLv
- 특수 정령 필터
- 근거리 타입
- 원거리 타입
- 마법 타입
- 경험치 성장용 정령
- HUD 도깨비 정보 UI
- 무한의 탑

## 숫자/상수/공식
- 강화 단계: 기본 0단계에서 시작, "+0"은 출력하지 않음
- 합성 재료: 4장 단위로만 등록
- 버프/디버프 최대 개수: 각각 최대 7개 (HUD 기본), 3개 (HUD 간소화)
- 스킬 정보 규격: 한 줄에 3~4개
- 경험치 표기: 소숫점 둘째 자리까지

- 정령 시스템_기본 및 강화
