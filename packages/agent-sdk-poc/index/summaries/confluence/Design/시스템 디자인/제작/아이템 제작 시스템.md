## 한 줄 설명
재료 및 재화를 소모하여 새로운 아이템을 제작하는 시스템으로, 아이템 드랍에 드는 장기간의 노력을 가시적으로 쪼개고 모든 유저가 재료만 있으면 공평하게 진행할 수 있도록 설계됨.

## 숫자/상수/공식
- 최대 8종류의 아이템 투입 가능
- 최대 2종류의 재화 투입 가능
- 즐겨찾기 최대 20개
- SuccessProb: 10000 = 100%
- LuckyProb: 10000 = 100% (성공 확률의 n%로 작동)
- 재료 반환 최대 3종
- 제작 결과 아이템: 1종류만 세팅 가능
- 재료 소모 우선순위: ① 인벤토리 CanStorage=FALSE → ② 인벤토리 CanAuction=FALSE → ③ 창고 CanAuction=FALSE → ④ 인벤토리 CanStorage=TRUE → ⑤ 창고 CanStorage=TRUE → ⑥ 인벤토리 CanAuction=TRUE → ⑦ 창고 CanAuction=TRUE
