# 캐릭터 임대 시스템 (요약)

> 출처: Confluence / 캐릭터 임대 시스템
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/캐릭터 거래_임대/캐릭터 임대 시스템/content.md

## 한 줄 설명
의뢰자가 캐릭터 소유권을 유지하면서 사용권만 수행자에게 임시 위임하여 일일 성장을 대신 이행받는 시스템으로, 외부 불법 대행을 게임 내로 흡수하고 의뢰 수수료로 수익화한다.

## 핵심 용어
- 의뢰자
- 수행자
- 캐릭터 임대
- 사용권 위임
- 소유권
- 의뢰 항목
- 의뢰금
- 다이아
- 에스크로
- 정산
- 달성률
- 페널티
- 점유 전환
- 배타적 조종
- 상태([OPEN], [INPROGRESS], [COMPLETED], [FAILED], [CANCELLED], [VIOLATED])
- 수수료(RentalFeePercentage)
- 미완료 페널티(RentalIncompletePenaltyPercentage)
- 응답 대기 시간(RentalAcceptConfirmSec)
- 세션 점유

## 숫자/상수/공식
- ContentSetting:RentalFeePercentage 기본값: 10%
- ContentSetting:RentalIncompletePenaltyPercentage 기본값: 50%
- 항목 달성률 = min(달성 수량 / 목표 수량, 1)
- 항목 달성분 = Sum(항목 의뢰금 x 항목 달성률)
- 의뢰자 환불 = 총 의뢰금 - 항목 달성분
- 수행자 지급 = 항목 달성분 x (1 - ContentSetting:RentalIncompletePenaltyPercentage)
- 등록 수수료 = 총 의뢰금 x ContentSetting:RentalFeePercentage
- 정산 예시(달성률 80%): 의뢰자 선지출 1100, 환불 200, 수행자 지급 400, 게임사 수익 500
