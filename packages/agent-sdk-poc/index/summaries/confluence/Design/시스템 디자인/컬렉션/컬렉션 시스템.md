## 한 줄 설명
지정된 아이템을 세트에 등록하여 달성 완료 시 스탯 보상을 주는 시스템으로, 획득한 스탯 효과는 동일 계정 내 동일 서버 캐릭터들끼리 공유된다.

## 숫자/상수/공식
- 컬렉션 세트 구성: 1~6개 아이템
- 장비 수량: 1개만
- 비장비 수량: 1개 이상
- 컬렉션 세트 ID: 6자리 (예: 100000)
- 보상 스탯: 복수개의 1차 및 2차 스탯효과 세팅 가능
- EffectStatName: 01~05 (최대 5개)
- TargetItem: 01~06 (최대 6개)
- ItemCount: 01~06 (최대 6개)
- CollectionCategoryGroupEnum: 1(전체), 2(즐겨찾기), 3(장비), 4(수집품), 5(이벤트), 6(숨긴 항목)
- CollectionCategoryEnum: 1(수집 재료), 2(업적), 3(스킬 재료), 4(이벤트)
- 아이템 그룹 형식: g{그룹ID} 또는 g{그룹ID}+{강화단계}
- 레드닷 표시: 일일 1회만 (컨텐츠 리셋 시간 기준)
