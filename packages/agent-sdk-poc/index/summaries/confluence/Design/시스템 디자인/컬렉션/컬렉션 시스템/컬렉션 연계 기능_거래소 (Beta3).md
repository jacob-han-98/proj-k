## 한 줄 설명
컬렉션 UI 내에서 거래소 매물을 검색·구매할 수 있는 기능으로, 일괄 구매 및 개별 구매 동선을 제공한다.

## 핵심 용어
- 컬렉션 UI
- 거래소 UI
- 거래소 이동 기능
- 일괄 구매
- 개별 구매
- 거래소 버튼
- 뒤로가기
- 닫기 버튼
- 최저 등록가
- 강화단계
- ItemCollectionClass
- TargetItem
- 하위 강화 단계
- 등록 시각 오름차순
- 보유 다이아
- 총 거래 금액
- 매물 리스트 팝업
- 장비 (Equip)
- 스택 아이템 (Consume, Etc)
- 개당 가격
- 등록 유효기간

## 숫자/상수/공식
- 거래소 리스트 1뎁스 상태
- 거래소 2뎁스 강화 단계 정보
- 거래소 3뎁스 정보
- 최저 개당 가격 (소수점 세째자리까지 올림처리)
- 실제 매물 표시 (20개까지)
