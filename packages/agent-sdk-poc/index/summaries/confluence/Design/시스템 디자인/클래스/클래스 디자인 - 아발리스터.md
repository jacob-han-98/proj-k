# 클래스 디자인 - 아발리스터 (요약)

> 출처: Confluence / Design/시스템 디자인/클래스
> 원본: packages/confluence-downloader/output/Design/시스템 디자인/클래스/클래스 디자인 - 아발리스터/content.md

## 한 줄 설명
시즈 모드 공격 시 순간 화력이 강한 누킹 딜러 클래스로, 체력이 높거나 보호막을 두른 대상에 강력한 딜링을 특화하며 회피/방어력으로 생존력을 보충하는 원거리 석궁 사용자의 클래스 디자인 문서.

## 핵심 용어
- 아발리스터 (Arbalester)
- 석궁
- 누킹 딜러
- 시즈 모드
- 강화탄
- 밀치기
- 파티 강화 버프
- 은신
- 마나번
- 체력 비례 피해
- 보호막 추가 피해
- 공성전
- 고정 전선
- 반동
- 궁극기
- 양산 영웅 급
- 투사체 (Projectile)
- 캐스팅 (Casting)
- 루프 (Loop)
- 히트 이펙트 (Hit FX)

## 숫자/상수/공식
- Idle 모션 재생 시간: 1.5초
- 기본 공격/스킬 애니메이션 재생 시간: 1.7초
- 전설 등급 달리기 애니메이션 재생 시간: 0.87초
- 스모크 파이어 범위(반지름): 1.5M
- PvE 조작 난이도: 보통
- PvP 조작 난이도: 어려움

## 참조 시스템
- PK_스킬 및 버프 아이콘_요청서.xlsx

## 주요 섹션
- 컨셉
- 기본 정보
- 애니메이션 리스트
- 전설 치환 애니메이션 리스트
- 스킬 이펙트 리스트
- 스킬/버프 아이콘 리스트
