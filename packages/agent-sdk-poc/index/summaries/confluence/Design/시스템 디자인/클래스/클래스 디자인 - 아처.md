## 한 줄 설명
Project K의 아처 클래스에 대한 컨셉, 기본 정보, 애니메이션, 이펙트, 아이콘을 정의하는 클래스 디자인 문서. 원거리 지속형 딜러로서 평타 버프 중첩 관리와 빠른 기동성을 특징으로 함.
