- 우선 순위 1, 2 항목: 5월 말 적용 목표
- 우선 순위 3, 4, 5 항목: Beta4 개선/폴리싱 일감 (IBT 이후 개발 목표)
- 길드 진입 제한 레벨: 15레벨 이전 불가
- 사망 페널티 장비 손실: 1~3개 (확률 지정 불가능 상태)
- 전투력 진행도 표기 예시: 20000 → 20090, 40000 → 40829
