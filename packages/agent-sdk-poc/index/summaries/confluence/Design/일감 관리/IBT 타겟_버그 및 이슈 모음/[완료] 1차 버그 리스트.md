## 한 줄 설명
Project K 1차 IBT 테스트 단계에서 발견된 33개의 버그 및 이슈를 우선순위별로 정리한 목록으로, 각 항목의 현상, 재현 과정, 기대 결과, 처리 상태를 기록한다.

## 핵심 용어
- 퀘스트 (메인 퀘스트, 서브 퀘스트, 일일퀘스트)
- 자동 진행 / 자동 이동 / 자동 전투
- 텔레포트
- 장비 아이템 / 장비 강화
- 장비 툴팁 / 아이템 툴팁
- 길드 / 적대 길드
- PK / PVP 모드
- 튜토리얼 (초반 튜토리얼, 인트로맵 튜토리얼, 아이템 장착 튜토리얼)
- 도깨비 (근거리, 원거리, 마법형)
- 정령의 탑
- 월드맵
- 자동사냥 / 자동 전투 범위
- 텍스트 키
- UI 겹침 / UI 정렬
- 애니메이션
- 캐릭터 생성
- 사망 패널티
- 전투력 UI
- 퀵슬롯
- 채팅창
- 단축키

## 숫자/상수/공식
- 우선순위: 1, 2, 3 (1이 최고)
- 자동 전투 범위 기본값: 20
- 텔레포트 기준 거리: 50m 이상
- 총 버그 항목: 33개 (행 1~33)

## 참조 시스템
- (없음)

## 주요 섹션
- 퀘스트 관련 버그 (자동 진행, 자동 수락, 진행 불가, 대화 중 전투)
- 장비 시스템 (아이템 효과, 툴팁, 강화 표시)
- 길드 / PK 시스템 (적대 길드 공격, 스킬 오류)
- 튜토리얼 (텍스트 키, UI 겹침, 간편 장착, 채팅창 간섭)
- UI 관련 (툴팁 겹침, 사각 박스, HP 게이지, 재화 UI)
- 맵 / 이동 (텔레포트 거리, 자동 이동 종료, 월드맵 텔레포트, 레벨 디자인)
- 캐릭터 / 직업 (도깨비 이름 표시, 애니메이션, 스킬 미리보기)
- 기타 (계정 생성, 치트 오류, 단축키 충돌, 전투력 UI)
