## 한 줄 설명
Project K 게임의 클라이언트 및 서버 버그, UI 오류, 게임플레이 이슈를 추적하고 관리하는 QA 이슈 트래킹 문서. 127개 항목의 버그 리포트, 재현 절차, 담당자, 진행 상태를 기록.

## 숫자/상수/공식
- PlayerResawnDelayTime = 30초
- 경로 찾기 실패 지점: 계단 초입, 아비시 대각선 옆
- 퀘스트 목표 수량 5마리 이상 진행 불가 (일부 케이스)
- 재현 빈도: 간헐적 (동일 방식, 동일 캐릭터로도 간헐적 발생)
- 호은 발생 확률: 약 92% (100% 아님)
- Rectangle 타입 범위 설정: 200, 500 => 4m, 10m (실제 10m 표시)
- 아틀라스 보스 필요 레벨: 42레벨 (UI에서 22레벨로 오표시)
