# 퀘스트 인스턴스 제작 (요약)

> 출처: Confluence / Design/제작 가이드/레벨 - 제작 가이드/퀘스트 인스턴스 제작
> 원본: packages/confluence-downloader/output/Design/제작 가이드/레벨 - 제작 가이드/퀘스트 인스턴스 제작/content.md

## 한 줄 설명
퀘스트 달성 시점에 인스턴스 입장/퇴장을 수행하고, 트리거 기반 몬스터 스폰을 제어하기 위한 엑셀 시트 및 에디터 작업 절차를 정의한다.

## 핵심 용어
- QuestObjective
- QuestInstanceStart
- QuestInstanceEnd
- QuestInstanceId
- QuestInstance
- worldId
- ReachVolume
- QuestInstanceTrigger
- Type (인스턴스 활성화 조건)
- ReachVolume (특정 볼륨에 도달)
- TalkToNpc (특정 NPC 대화)
- KillMonster (특정 몬스터 처치)
- KillSpawnVolume (특정 스폰볼륨 몬스터 모두 처치)
- Arg 0 ~ 2
- QuestTriggerSpawnVolumeId
- MonsterSpawn.xlsx - QuestTriggerSpawn
- RepeatSpawn
- WorldClass.xlsx
- OriginWorldId
- PlayerSpawnVolume
- MonsterSpawnVolume
- QuestVolume
- InstanceVolume
- Use Instance
- 퍼블릭 월드

## 숫자/상수/공식
- RepeatSpawn: 2 이상 숫자 입력 시 여러 번 스폰
- 기준 날짜: 2025.04.04

## 참조 시스템
- Quest.xlsx
- WorldClass.xlsx
- MonsterSpawn.xlsx
- WorldClass.xlsx - id 값

## 주요 섹션
- 참고 사항
- 필요 파일 및 설명 (Quest.xlsx - QuestObjective, Quest.xlsx - QuestInstance, Quest.xlsx - QuestInstanceTrigger, WorldClass.xlsx, MonsterSpawn.xlsx - QuestTriggerSpawn)
- 필요 작업 - 에디터 (공통 작업 사항, InstanceVolume, PlayerSpawnVolume, MonsterSpawnVolume, QuestVolume)
