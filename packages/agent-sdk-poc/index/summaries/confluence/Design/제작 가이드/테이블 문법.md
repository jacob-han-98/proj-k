# 테이블 문법 (요약)

> 출처: Confluence / Design/제작 가이드/테이블 문법
> 원본: packages/confluence-downloader/output/Design/제작 가이드/테이블 문법/content.md

## 한 줄 설명
Project K 시스템 기획 문서에서 사용되는 다양한 테이블 입력 문법과 규칙을 정의한 매뉴얼.

## 핵심 용어
- 테이블 문법
- ItemId
- EnchantLv
- 장비 아이템 강화
- 그룹
- Collection
- EffectClass
- Max 컬럼
- BonusEnum
- 스탯 상한선
- 스킬별 스탯 효과
- 에러 처리

## 숫자/상수/공식
- {ItemId}+{EnchantLv} (예: 1000+7)
- g{ItemId} (예: g1000, g1000+7)
- {BonusEnum}={상한선 값} (예: AllAttack=5, MaxHp=500)

## 참조 시스템
- Collection 테이블 파일
- EffectClass 테이블 파일
- 장비 강화 시스템

## 주요 섹션
- 장비 아이템 강화
- 그룹
- 스킬별 스탯 효과의 상한선
