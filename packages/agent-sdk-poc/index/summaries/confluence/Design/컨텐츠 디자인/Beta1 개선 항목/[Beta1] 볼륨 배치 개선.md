## 한 줄 설명
Beta1 단계에서 게임 레벨의 몬스터 스폰, 퀘스트 입장 등에 사용되는 볼륨의 배치 방식을 개선하기 위한 기획으로, 스케일 값 적용, 회전 기능 제한, 몬스터 뭉침 현상 해결 등을 다룬다.
