## 한 줄 설명
Beta1 단계에서 월드맵 UI/UX 개선 및 자동 이동, 미발견 지역 표시, 드랍 아이템 정렬, 국가명 표시 등 기능 개선 사항을 정의한 문서.

## 핵심 용어
- 자동 이동
- 텔레포트
- 미발견 지역
- Territory
- 월드맵 확대/축소
- 줌 배율
- 드랍 아이템 정렬
- 국가명 표시
- WorldCountry
- WorldTerritory
- DA_ClientDesignDataAsset
- 지역 아이콘
- 지역명
- 추천 레벨
- 자동 이동 메시지
- 셀레탄
- 스켈라
- 배반자들의 소굴
- 환청의 그늘
- 물이 활퀸 땅

## 숫자/상수/공식
- 텔레포트 거리 제한: 50m 이내 시 자동이동으로 변경
- 줌 배율 자동 변경 기준: 2.5 (2단계와 3단계 중간값)
- 최대 줌 단계: 4단계
- 드랍 아이템 정렬 우선순위: 아이템 타입(장비 > 재료 > 소모품) > 등급(전설 > 영웅 > 희귀 > 고급 > 일반) > 아이템 ID 오름차순

## 참조 시스템
- 월드 및 지역 표시 시트 - ③ 월드 표시 항목

## 주요 섹션
- 기존 기획서 작성 스펙
- 임의지역 자동 이동 기능
- 미발견 지역 표시
- 월드맵 개선
- 월드맵 확대/축소 조작감 개선
- 지역 정보 내 드랍 아이템 정렬 순서 변경
- 월드맵 축소 시 국가명 표시
- 월드맵 자동 이동 시 표시 대응
- 월드맵 비율 별 아이콘 메시지 비율 조정
- 신규 지역 추가 대응
