## 한 줄 설명
퀘스트 자동 진행 시스템의 볼륨 탐색 로직, 대상 탐색 범위, 컷신 처리를 개선하여 플레이어 경험을 향상시키는 기획안.

## 핵심 용어
- 퀘스트 자동 진행
- 볼륨 (Volume)
- 자동 진행 목표 볼륨
- 대상 탐색
- 시퀀스 볼륨
- 컷신 (Cutscene)
- VolumeSequence
- PlayOnce
- QuestObjective
- CompleteCinematicId
- 볼륨 중심
- 입장 볼륨
- 자동 전투

## 주요 섹션
- 이슈1: 다중 볼륨 시 가장 먼 볼륨으로 이동하는 현상
- 이슈2: 단일 볼륨 입장 후 대상 탐색 실패 시 중심 이동 중 대상 통과 현상
- 이슈3: 시퀀스 볼륨 진입 중 컷신 재생 중 캐릭터 이동 현상
- 볼륨 다수 개일 때 이동 방식 개선
- 볼륨 내부에서 기본 탐색 방식 개선
- 컷신 대응 추가
- 자동 진행 실패 안내 추가
