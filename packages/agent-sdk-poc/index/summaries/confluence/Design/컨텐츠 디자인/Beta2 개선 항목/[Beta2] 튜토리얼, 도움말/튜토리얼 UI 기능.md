## 숫자/상수/공식
- 조작 튜토리얼 구분자: 1001, 1002, 1003, 1004, 1005
- 도움말 UI 연결 구분자: 101, 201, 301, 401, 501, 601, 701
- 화면 좌/우측 가장자리로부터 20~30% (약 25%) 이내 영역
- 화면 기준 70~80% (약 25%) 이상 드래그 이동
- 최소 인식 거리 (테스트 필요)
- 아이콘 사이즈 최소 44px 이상
- 도움말 설명 3줄까지 표현 가능
- 최대 5개 이미지로 구성
