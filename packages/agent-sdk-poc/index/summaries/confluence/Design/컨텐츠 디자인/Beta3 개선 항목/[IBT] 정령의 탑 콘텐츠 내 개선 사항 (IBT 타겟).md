## 한 줄 설명
정령의 탑 콘텐츠의 원활한 플레이를 위해 패배 UI 출력, 오브젝트 스폰 타이밍, 탑 진입 시 UI 배치 등 3가지 개선 사항을 정리한 문서.

- 패배 UI
- 수호 오브젝트
- HUD
- 오브젝트 스폰 타이밍
- 테리토리 변경 UI
- 정보성 UI
- InfiniteTowerSpawn 테이블
- WaveNumber
- 필드 진입
- 카운트 다운
- WorldId
- WorldTerritory
- 섬멸전
- 플레이어 사망
- 수호 타워

## 숫자/상수/공식
- WaveNumber=0 (필드 입장 시 스폰)
- WaveNumber=1~3 (현재 섬멸전 등에서 사용)
- WaveNumber=1 (카운트 다운 종료 시 소환)
- WorldId=1001 (정령의 탑)
