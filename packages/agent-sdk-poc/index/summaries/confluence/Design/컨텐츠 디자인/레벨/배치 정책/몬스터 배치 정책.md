## 한 줄 설명
Project K에서 로컬 월드의 사냥터에 몬스터를 배치하고 제어하는 기준과 규칙을 정의하며, 공간 구성, 비Stat 몬스터 타입, 사냥터-몬스터 조합을 체계화한 문서.

## 숫자/상수/공식
- 화면 내 적정 동시 사냥 유저 수: 4명
- 화면 내 적정 몬스터 개체: 15개체 (중~중대형 기준)
- 화면 내 총 개체 (유저 포함): 약 20개체
- 대형 몬스터 한계점: 15개체
- 근거리/원거리 혼합 비율: 1:0 ~ 1:1 (점진적 상승)
- 물리/마법 혼합 비율: 1:1 (후반)
- 근거리 물리 후공 SearchRange: 250
- 근거리 선공 SearchRange: 800
- 원거리 후공 SearchRange: 250
- 원거리 선공 SearchRange: 800
- MoveRange 기준: Scale 1 = 120
- SpawnNumberMin: 기준 개체 수의 90%
- SpawnNumberMax: 기준 개체 수의 110%
- 리스폰 주기 기준: 80%
