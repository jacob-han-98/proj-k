## 한 줄 설명
소르브 국가의 마지막 필드로, 몰락한 왕국의 황폐한 협곡을 배경으로 라그나르 왕과의 최종 대결을 펼치는 필드의 레벨 설계 및 배치 기획서.

## 숫자/상수/공식
- 크기: 300X300
- 메인 동선 폭: 6m 이상
- 거인의 함 크기: 3mX1m
- 필드 순서: 6번째 (해오름 언덕 → 노을 평야 → 풍요의 들판 → 성난 폭풍의 평원 → 부서진 유적 → 몰락의 협곡)
- 리전 구분: 5개 리전
- 거점 배치: 필드 내 2곳
