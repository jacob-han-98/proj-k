## 한 줄 설명
물이 할퀸 땅 필드를 200X200에서 300X300으로 확장하여 사냥터 부족 현상을 해결하고, 리전 2개와 밀수상인 공간, 추가 거점을 배치하는 맵 확장 설계.

## 숫자/상수/공식
- 현재 맵 사이즈: 200X200
- 확장 목표 사이즈: 300X300
- 사냥터 크기: 30X30 (기존과 동일)
- 추가 리전: 2개
- 리전당 사냥터: 4개
- 추가되는 총 사냥터: 8개
- 확장 후 총 사냥터: 20개
- 밀수상인 공간 사이즈: 20X20
- 추가 거점 사이즈: 20X20
- 입구 최소 크기: 10m 이상
