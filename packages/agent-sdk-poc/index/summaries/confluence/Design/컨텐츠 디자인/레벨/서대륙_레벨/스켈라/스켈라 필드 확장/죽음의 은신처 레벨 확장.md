## 한 줄 설명
죽음의 은신처 맵을 200X200에서 300X300으로 확장하여 사냥터 부족 현상을 해결하고, 리전 2개와 밀수상인 공간, 추가 거점을 배치하는 레벨 확장 계획.

## 숫자/상수/공식
- 현재 맵 사이즈: 200X200
- 확장 후 맵 사이즈: 300X300
- 사냥터 크기: 30X30
- 기존 사냥터 개수: 12개
- 추가 사냥터 개수: 8개
- 확장 후 총 사냥터 개수: 20개
- 추가 리전 개수: 2개
- 리전당 사냥터 개수: 4개
- 밀수상인 공간 사이즈: 20X20
- 추가 거점 사이즈: 20X20
- 입구 최소 크기: 10m 이상
- 입구 최소 개수: 2개 이상
