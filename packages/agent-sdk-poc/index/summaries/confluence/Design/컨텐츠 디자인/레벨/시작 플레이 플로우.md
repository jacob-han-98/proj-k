## 숫자/상수/공식
- 3-5분 플레이 (인트로 던전 플레이 시간, 영상 재생·로딩 제외)
- 1인용 인스턴스 던전
- 클래스별 1회 플레이 완료 정보 저장
- 총 1종 (독립된 별도 월드)
- 총 2종 (클래스별 레벨: 동대륙형/서대륙형)
- 총 6벌 (클래스별 전용 퀘스트)
