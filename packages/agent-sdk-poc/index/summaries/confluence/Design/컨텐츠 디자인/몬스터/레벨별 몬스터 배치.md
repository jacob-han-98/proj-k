## 한 줄 설명
Project K의 동대륙과 서대륙 지역별 몬스터 배치 현황을 레벨 1~69 범위에서 정의하며, 각 몬스터의 리소스명, 등급(normal/named), MonsterId를 기록한 beta3 기준 배치 문서.

- 리소스명
- 등급(normal, named)
- 동대륙
- 서대륙
- 사그라진 성터
- 그림자 무덤가

- 오염된 농장
- 남부 해안가
- 칼날 바람 절벽
- 배반자들의 소굴 동부
- 배반자들의 소굴 서부
- 환청의 그늘 동부
- 환청의 그늘 서부
- 숭배의 언덕

- 죽음의 은신처

## 숫자/상수/공식
- 레벨 범위: 1~69
- 동대륙 최고 레벨: 31 (거인의 숲, 핏빛 거대 토우 신장)
- 서대륙 최고 레벨: 57 (숭배의 언덕, 라자루 왕)
- 신대륙 최고 레벨: 69 (죽음의 은신처, 페리안느 왕)
- normal 등급: 대다수 몬스터
- named 등급: 각 지역 보스 몬스터 (약 1~2마리/지역)
