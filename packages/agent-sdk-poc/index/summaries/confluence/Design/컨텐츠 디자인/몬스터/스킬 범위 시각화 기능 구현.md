# 스킬 범위 시각화 기능 구현 (요약)

> 출처: Confluence / Design/컨텐츠 디자인/몬스터/스킬 범위 시각화 기능 구현
> 원본: packages/confluence-downloader/output/Design/컨텐츠 디자인/몬스터/스킬 범위 시각화 기능 구현/content.md

## 한 줄 설명
에디터 뷰포트에서 스킬 범위를 실시간으로 시각화하여 데이터 반복 입력 없이 범위값을 세팅 및 확인할 수 있는 기능 구현 명세서.

## 핵심 용어
- Area Preview Settings
- AreaShape
- AreaSize
- Area Standard
- Caster
- Target
- Circle
- Rectangle
- Arc
- PKHit 노티파이
- PK Skill Visualizer
- 애님 몽타쥬
- 노티파이 스테이트
- 뷰포트
- Editor Preview Location
- AreaLocation
- Life Time
- Thickness
- 에디터 환경
- 인게임 플레이

## 숫자/상수/공식
- Circle: 반지름 1개 값 (예: 250)
- Rectangle: 가로, 세로 2개 값 (예: 75, 350)
- Arc: 반지름, 각도 2개 값 (예: 700, 60)
- Area Location: x축, y축 오프셋 (예: 0, 350)
- 몽타쥬 타임라인 프레임 예시: 30~40f

## 참조 시스템
- Skill 테이블

## 주요 섹션
- 개요
- 문서 의도
- 작업 요청 스펙
- 수정 시 예상 프로세스
- 작업 완료 버전 공유 및 가이드
- 프리뷰 확인 방법
- 작업 예시
- 애님 몽타쥬 - 노티파이 스테이트 추가
- 애님 몽타쥬 - 뷰포트 출력
- 추가 요청 사항
