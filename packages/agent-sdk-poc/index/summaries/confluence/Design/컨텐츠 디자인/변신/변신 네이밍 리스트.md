## 한 줄 설명
Project K의 변신 시스템에서 클래스별·등급별 변신 형태에 대한 두 가지 네이밍 버전(VER.1, VER.2)을 정의한 리스트.

## 핵심 용어
- 가디언
- 워리어
- 아처
- 아발리스터
- 샤먼
- 매지션
- 일반 등급
- 고급 등급
- 희귀 등급
- 영웅 등급
- 전설 등급
- 스토리 영웅
- 명칭 VER.1
- 명칭 VER.2
- 가명
- 뱀피르 방식
- 동일 리소스
- 동일 수식어
- 클래스별 고유 명사

## 숫자/상수/공식
- 일반 등급: 4개 수식어
- 고급 등급: 7개 수식어
- 희귀 등급: 7개 수식어
- 영웅 등급: 6개 수식어
- 전설 등급: 클래스당 2개 형태
- 총 168개 네이밍 항목

## 참조 시스템
- (없음)

## 주요 섹션
- 버전 1 설명 (동일 리소스 시 동일 수식어, 클래스별 고유 명사)
- 버전 2 설명 (뱀피르 방식 참고, 등급별 동일 수식어, 클래스별 고유 명사)
- 변신 네이밍 테이블 (NO, 등급, 가명, 명칭 VER.1, 명칭 VER.2)
