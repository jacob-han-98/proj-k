## 한 줄 설명
Project K 게임 내 퀘스트 진행에 사용되는 상호작용 가능한 오브젝트 80종의 메시 경로, 위치, 용도, 아트 스펙을 정의한 마스터 리스트.

## 핵심 용어
- QuestObjectMesh
- 돌 더미
- 나무 상자
- 시체
- 항아리
- 화로
- 묘비 비석
- 아나디스 열매
- 천 조각
- 우물
- 침낭
- 포대 자루
- 책
- 향로
- 마차
- 함정
- 오크통
- 나무 기둥
- 처형대/고문도구
- 투명 상자

## 숫자/상수/공식
- 총 80개 오브젝트 번호 (No. 1~80)
- 스케일 0.75 (No. 5 마차)
- 스케일 1.25 (No. 22 해골, 돌림병 발원지 관련)
- 충돌제거 (No. 22 해골 관련)

## 참조 시스템
- (없음)

## 주요 섹션
- 오브젝트 구분 (돌 더미, 상자류, 시체, 자연물, 도구류 등)
- QuestObjectMesh 경로 (언리얼 엔진 에셋 경로)
- 위치 (지역명: 사그라진 성터, 배반자들의 소굴, 환청의 그늘 등)
- 오브젝트 내용 (퀘스트 상황별 명칭)
- 기획 (신규 리소스 제작 요청 사항)
- 아트 (스케일, 충돌 설정 등)
