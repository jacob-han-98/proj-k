## 숫자/상수/공식
- 대화 목표 소요 시간: 5초 (건너뛰기 기준)
- 이동 목표 소요 시간: 5초 (텔레포트 기준)
- 오브젝트 목표 소요 시간: 5초 (인터랙션 기준)
- 처치 목표 소요 시간: 350초 (시작 지역 100초 / 후반 지역 600초)
- 수집 목표 소요 시간: 420초 (시작 지역 10초 / 후반 지역 780초)
- 퀘스트당 기본 목표 개수: 3개
- 런칭 기준 필요 맵 수: 35개 (일반 필드 28 + 도시/마을 6 + 인트로 던전 1)
- 메인 퀘스트 전체 합산: 270개
- 메인 퀘스트 맵별: 8~10개
- 메인 퀘스트 리전별: 2개 (네임드 포함 리전 3개)
- 메인 퀘스트 맵별 총 수행 목표: 8~9개
- 메인 퀘스트 리전별 목표 구성: 대화 3 + 이동 2 + 오브젝트 1 + 처치 2 + 수집 1 = 9개
- 네임드 포함 리전 추가 가능: 각 목표별 +1
- 서브 퀘스트 전체 합산: 212개
- 서브 퀘스트 맵별: 8~14개
- 서브 퀘스트 리전별: 2개 (바리울 초반 지역 1개)
- 서브 퀘스트 맵별 총 수행 목표: 8개
- 서브 퀘스트 리전별 목표 구성: 대화 n + 오브젝트 n + 처치 1 또는 수집 1~2 = 4개
- 일간 퀘스트 기본 개수: 리전별 처치 가능 몬스터 그룹 대상
