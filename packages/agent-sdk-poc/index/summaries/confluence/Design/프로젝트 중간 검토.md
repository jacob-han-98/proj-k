## 한 줄 설명
Project K의 게임 방향성을 명확히 하고, 개발 항목을 구조화하며, 남은 일정에 대한 작업 계획을 수립하기 위한 중간 검토 문서.

- 한국식 MMORPG
- 복식(변신)
- 발동액션
- 후판정
- 궁극기
- 종적성장
- 횡적성장
- 동양 퓨전 다크판타지
- 반실사 그래픽
- 다크판타지 톤
- 진성 유저
- 중소과금러
- 경쟁 랭킹 다각화
- 배틀 커뮤니티 순화
- 경제 활동 난이도

- 컨텐츠 컨셉

## 숫자/상수/공식
- 작성 시점: 2025년 11월 25일
- 목표 시점: 2025년 12월 24일
- 동양컨셉 비중: 20~30% (중세 쪽 70~80%)
- 6종 클래스 기반 (알파2)
- 근원마 3종 기반: 검사/궁사/법사
