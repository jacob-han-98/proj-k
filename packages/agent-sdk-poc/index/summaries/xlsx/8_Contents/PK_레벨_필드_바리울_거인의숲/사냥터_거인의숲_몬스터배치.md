- 선공/비선공

- 몬스터 밀집도
- 상위 등급 몬스터

## 숫자/상수/공식

- 배치 몬스터 수: 일반 2~5개, 보스 1개
- 배치 그룹 ID 범위: 10104101~10104541
- 스폰 지점 인덱스: 각 그룹 내 2~15개 지점
