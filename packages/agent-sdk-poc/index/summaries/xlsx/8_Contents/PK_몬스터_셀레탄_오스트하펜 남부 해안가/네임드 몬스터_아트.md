## 한 줄 설명
셀레탄 오스트하펜 남부 해안가 지역의 네임드 몬스터에 대한 애니메이션 및 FX 리소스 정의 문서. 기본 모션, 스킬 시전, 피격 상태 등의 애니메이션 리소스명, 루프 여부, 동작 설명, 예시 이미지를 명시한다.
