## 숫자/상수/공식
- 필드 크기: 약 300m x 300cm (조정 가능성 높음)
- 기준 PC Lv: 20~30 Lv
- 몬스터 사냥 속도: 5~8 sec (전투 개시~종료)
- 몬스터 피해량 기준: 포션 0.5~0.75개 사용 (전투 개시~종료)
- 몬스터 개체 수 기준 - 극소: 1~3 / 소: 4~7 / 중: 8~11 / 대: 12~15 / 특대: 16+
- 현재 필드 개체 수: 특대 (16+)
- 스폰 주기 - 매우 빠름: 5~8 sec / 빠름: 9~11 sec / 중간: 12~15 sec / 느림: 16~20 sec / 매우 느림: 21~40 sec
- 현재 필드 스폰 주기: 매우 빠름 (5~8 sec)
- 필드 몬스터 구성: 필드 보스 1종 + 일반 몬스터 10종
