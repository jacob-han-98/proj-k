## 숫자/상수/공식
- 필드 크기: 약 15000cm x 20000cm
- 기준 PC Lv: 10~20 Lv
- 몬스터 사냥 속도: 5~8 sec (전투 개시~종료)
- 몬스터 피해량 기준: 포션 0.5~0.75개 사용
- 몬스터 개체 수: 특대 (16+)
- 몬스터 스폰 주기: 매우 빠름 (5~8 sec)
- 극소 개체 수: 1~3
- 소 개체 수: 4~7
- 중 개체 수: 8~11
- 대 개체 수: 12~15
- 특대 개체 수: 16+
- 노 리스폰: - (이벤트, 보스 등 특수)
- 매우 느림 리스폰: 21~40 sec
- 느림 리스폰: 16~20 sec
- 중간 리스폰: 12~15 sec
- 빠름 리스폰: 9~11 sec
- 매우 빠름 리스폰: 5~8 sec
- 핫스팟 개수: 5종 (중앙 1 + 십자로 4)
- 필드 몬스터 구성: 필드 보스 1종 + 일반 몬스터 10종
