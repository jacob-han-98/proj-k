## 숫자/상수/공식
- 평타 재생 시간: 1초
- 발동 액션 재생 시간: 1~1.2초
- 스킬 재생 시간: 1.2~1.5초
- 빙룡의 가호: 쿨타임 15초, 지속시간 12초, 빙속성 공격 20% 강화
- 얼음 가시: 발동 확률 10%, 쿨타임 8초, 공격 횟수 2, 오한 적용 확률 70%, 지속시간 10초
- 폭발하는 물웅덩이: 발동 확률 10%, 쿨타임 8초, 젖음 적용 확률 80%, 지속시간 10초
- 잔혹한 물결: 발동 확률 10%, 쿨타임 2초, 젖음 적용 확률 50%, 지속시간 5초
- 얼음 폭풍: MP 소모 15, 쿨타임 8초, 오한 적용 확률 50%, 지속시간 10초
- 급속 빙결: MP 소모 40, 쿨타임 15초, 공격 횟수 2, 빙결 적용 확률 100%, 지속시간 5초
- 깨어나는 빙룡: MP 소모 20, 쿨타임 12초, 공격 횟수 2
- 견고한 물방울: MP 소모 40, 쿨타임 15초, 스턴 적용 확률 30%, 젖음 적용 확률 100%, 지속시간 3초/10초
- 젖음/오한: MoveSpeedRate -1500, AttackSpeedRate -1000, SkillSpeedRate -1000
- 빙결: AllActionDisable 10,000
- 속성 피해 계산: ② x (ElementalDmgBoostRate / 10000)
- 치명타 미적용: (① + ②) - ③ = < 1, 1
- 치명타 적용: ((① + ②) * 1.5) - ③ = < 1, 1
