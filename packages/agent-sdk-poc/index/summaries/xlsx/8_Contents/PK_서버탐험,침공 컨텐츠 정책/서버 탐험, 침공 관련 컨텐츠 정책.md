## 한 줄 설명
서버 탐험 및 침공 시스템의 컨텐츠 팀 담당 요소(퀘스트, NPC, 상점)를 정의하고, 퀘스트 지급 룰 개선, 밀수 상인·경비병 배치, 침공 결계 규모, 차원의 상점 운영 정책을 수립한 기획 문서.

## 숫자/상수/공식
- 최대 침공 인원: 50명
- 침공 공간 구성: 1종의 거대 보스 + 최대 50인의 외부 서버 PC + 무작위의 원 서버 PC
- 각 필드당 밀수 상인 배치: 1기
- 각 사냥터마다 밀수 상인 배치: 1기
- 퀘스트 지급 방식: 레벨 단위 QuestPrerequisite 설정 (Level_Min / Level_Max)
