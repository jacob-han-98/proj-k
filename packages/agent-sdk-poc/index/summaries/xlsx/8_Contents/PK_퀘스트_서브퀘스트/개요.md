## 숫자/상수/공식
- Beta1 총 퀘스트 수: 243개
- 대화 기준 타임: 5초 (1차, 2차)
- 이동 기준 타임: 5초 (1차, 2차)
- 오브젝트 기준 타임: 5초 (1차, 2차)
- 처치 기준 타임: 180초 (1차), 300초 (2차)
- 수집 기준 타임: 216초 (1차), 625초 (2차)
- 액트 범위: 1~99
- 챕터 범위: 1~9
- 퀘스트 구분 범위: 1~999
- 볼륨 구분 범위: 1~999999
- 퀘스트 ID 자릿수: 6자리 (예: 8 1 1 01 1 01)
- Volume ID 자릿수: 4자리 (예: 8 01 1 0001)
- Dialog ID 규칙: Quest ID 맨 앞자리 8 제거 후 7자리 + 접미사(0~6, 9)
